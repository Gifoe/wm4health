# Independent evaluation rule, before opening EVAL

Run after all16 selected weights and VAL estimator allocations are frozen. Never change weights, function definitions, thresholds, allocations, or model selection from EVAL outcomes. EVAL consists of64 independently generated trajectories per carrier. The query subset is its fixed first4 histories. These are controlled carriers, not evidence of real-domain generalization or a new world-model contribution.

Full-law quality:64 iid conditional future paths per history; save all paths, targets, seeds and selected-checkpoint hashes. Report joint future U-statistic energy normalized by sqrt(1024), mean-prediction MSE and marginal90% interval coverage. Independently recompute scores from saved arrays. The latter two are diagnostics and cannot replace a joint-law criterion. Across-family objectives, representations and compute are different; this is a strong utility control, not an isolated architectural ranking. Two training initializations do not establish universal stability.

Truth queries: use only the observed history, known generative process and TRAIN normalization. Gaussian reference uses an exact Kalman posterior and65536 iid future draws. Nonlinear reference uses bootstrap particle filtering at16384 and65536 particles, two independent filters/count,32768 future draws/filter. Compare per-function means across counts against max(5 conditional-MC standard errors, .02 TRAIN function standard deviations). If that test fails for a context, automatically run262144 particles with two independent filters and compare the last two counts under the same rule. If still unresolved, label truth accuracy unresolved; do not tighten claims by ignoring the failed context. Gaussian PF comparison is a numerical control against the exact posterior. Report conditional-MC uncertainty, between-filter variation, particle-count differences and ESS separately. Reusing the qualified numerical reference kernel is disclosed; it is not an independent reimplementation. Never condition on the hidden state that generated a particular evaluation trajectory.

Same-fitted-law query references and16-replicate estimator evaluation remain a separate required phase of the original protocol. Passing full-law scoring or truth-reference convergence is not a substitute. No query-method benefit or candidate acceptance may be claimed while those comparisons are pending. Timing must include actual allocated calls, prefix/moment setup, function computation, result transfer and pilot amortization. Analytic learned-law expectations have zero sampling error about that learned law; their true-process bias remains measurable.

Source/execution failures are retained and repaired in new script versions. No public publication, old-result deletion or unrelated project change is part of this phase.
