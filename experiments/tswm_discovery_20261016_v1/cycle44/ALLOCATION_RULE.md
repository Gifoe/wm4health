# Query allocation rule — frozen before any pilot query results

Run only after all16 training selections are terminal. EVAL remains closed during this stage. Four fixed first VAL histories,1024 standard base draws and their antithetic counterparts per history, microbatch64. Use the five fixed TRAIN-scaled functions. Costs include sampling and all five function evaluations; all policies are charged that same multi-function evaluation cost even when only one function is requested. Record per-history prefix/cache setup separately. Cache ordinary deterministic conditioning/prefix computations for all families, with numerical parity checks; do not count caching as a new model.

For each function, average the conditional variance over the four VAL histories (do not pool conditional means). Record coefficients V_G*C_F, Var[(G+Ganti)/2]*2C_F, (sqrt(V_C*C_C)+sqrt(V_delta*C_pair))², and their antithetic counterparts. Native SPF pairs use separate native coarse/fine calls with the same base RNG seed; the independent coarse term will use a distinct seed. LGSSM pairs may use the actual fine temporal mean, with a separately sampled analytic coarse Gaussian marginal. AR has MC and antithetic MC only. There is no sorting/re-pairing of a finite batch: such dependent pairs cannot be treated as iid corrections with Var(delta)/N.

For fine-equivalent budgets128/512/2048, enumerate feasible nonzero level counts in multiples64 under measured cost. MC usesB draws, antithetic MC usesB/2 base pairs. MLMC must pay for both independent coarse and paired correction calls; antithetic level units cost twice. Choose the policy/counts with minimum predicted variance using VAL only, separately for each function and budget. If no multilevel allocation fits or improves predicted variance, choose an ordinary MC policy. MC and antithetic MC are always retained as EVAL comparisons; selected policies that duplicate them are labeled duplicates, not new methods.

Calibration cost is charged separately and amortized over1/100/1000 single-function requests; do not hide it. Sampling-cost predictions must be accompanied by actual allocated-call timing checks in the EVAL phase. Statistical estimator replicates may reuse nested disjoint raw-function pools across budgets; disclose this and do not report pool generation time as if it were the deployment time of every policy. Independently generated fitted-law reference uses at least16384 draws and reports its standard error. Report empirical errors with reference uncertainty as well as the variance-based unbiased-estimator calculation. No claimed precise gain may rely on differences smaller than reference uncertainty.

The additional ordinary controls in ANALYTIC_CONTROLS.md are eligible policies before any query effects: conditional/Rao–Blackwell readouts and their antithetic versions, and exact learned-LGSSM readouts for functions1/3/4. They use the same selected model weights. Analytic rows have zero sampling variance and separately measured fixed moment/query setup; they are not free total cost. For marginal readouts, enumerate counts under measured sampling cost in the same64-unit convention. Include these contenders when judging whether a new world-model architecture is necessary. This fixed diagnostic function suite is not evidence of arbitrary-query generalization.
