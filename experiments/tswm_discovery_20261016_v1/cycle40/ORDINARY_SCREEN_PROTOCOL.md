# C40 ordinary screen protocol (before real VAL scoring)

Scope: first ordinary recurrent-state / direct-conditioner screen for a framework question. This is component transfer to a shared diagnostic contract, not authors' headline reproduction and not a proposed method. No conclusion against all ordinary updating methods is possible until SFM and appropriate state-space controls are included.

Data: ETTh1 OT and Jena Beutenberg 2016 T (degC), provider bytes/hash and hourly cadence audited in intake. Jena takes timestamps at minute zero, not interpolation. Chronological 70/15/15 split, all 192 history + 96 future values inside each split, incomplete windows excluded. Train-only fixed mean/std. TEST remains unscored. These are new diagnostic splits, not official benchmark reproduction splits. No covariates other than deterministic time coordinates; both families receive the same information.

Pre-training V3 correction: the official Jena archive has a 75-hour gap between successive hourly observations. Reindex the timestamp grid to hourly, mark inserted slots NaN and exclude incomplete windows. No interpolation, concatenation across gaps or replacement of signal values. V1 network failure and V2 timestamp-precheck failure are preserved. This change precedes any real validation score or model fit.

Contract: each origin has history 192, future 96, fixed target B=future[64:96]. Reveal actual future prefixes r in {0,8,32}, preserve old history and coordinates. Unknown gap is integrated/generated, never observed. Chronological validation origins with stride 32. Selection uses at most 32 evenly spaced origins; these are a subset of exploratory VAL, not an independent confirmation set. Final screen scores all stride-32 VAL origins. Fixed TEST indices are saved without scoring.

Families: (a) 2-layer, width-256 GRU latent-state autoregression with 8-component Gaussian-mixture innovations, non-Gaussian conditional law, recurrent cache; (b) fixed original FlowNP source f3403b6479dad33a7b93ba6edcf93c53d40f8e65, d_model128/layers4/ff256/heads4/position16. Native target-wise independent training times and public augmented/noisy predict() preserved. Read .loc as generated trajectories; fake_output_scale=.001 is a source compatibility placeholder. Architecture sizes and 100-step synthetic cost recorded before training. No requirement of exactly equal parameters; actual capacity/compute differences limit conclusions.

Seeds 2026401 and 2026402, 2 families x 2 data x 2 seeds = 8 fresh fits. AdamW lr3e-4, weight_decay.01, batch32, clip1, 2000 updates; fixed schedule, no test selection. Family-specific likelihood versus flow loss is standard. Flow queries cycle r=0/8/32 on the same pre-generated origin minibatch schedule; AR trains the future96 joint likelihood and therefore natively supports every prefix. Validate at steps 0/500/1000/1500/2000. Select by mean fixed-B fair energy score/√32 over all r, using 32 iid paths. Last checkpoint and all curves retained. A selected cap, improving final validation, or large family asymmetry means budget limitation, not a new-method gap. No dataset-specific retuning in this screen.

Final evaluation: 32 iid paths, all r; FlowNP steps1/2/8/32, same selected checkpoint; AR native ancestral draws with actual-gap generation. Fair energy primary; marginal CRPS, whole-B mean CRPS, MAE, 80% coverage secondary. No independent-seed inference from only two seeds. Temporal-block descriptive intervals use blocks of 168 hours; overlapping origins are never treated as independent samples. Paired origin results retained.

Cost: report model parameters, actual fit/update/evaluation time and peak memory. Record full conditioning+32draw end-to-end per query, history-cache build and incremental evidence update separately for AR. Time CUDA-synchronized; exclude load and report warm-up policy. FlowNP has no reusable native history cache in this API; do not count omitted setup as a speed gain. Source generation/distillation not performed or treated as free.

Decision: this is a baseline adequacy screen only. No numerical threshold promotes a new idea. Ordinary quality/cost tradeoffs inform the next control. A residual requires correct-source replay, capacity/budget diagnostics and SFM before attributing it to missing state-learning mechanisms. No TEST scoring or longer fit is triggered merely by a desired positive result.
