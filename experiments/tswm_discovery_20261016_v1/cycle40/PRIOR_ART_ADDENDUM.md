# C40 focused primary-source novelty check

Checked 2026-10-17, after framework-scope correction. These are literature findings, not executed baselines or results from this server.

- **LIFTS**, arXiv:2610.03916v1, 2026-10-02. [Primary full text](https://arxiv.org/html/2610.03916v1), §§2–5. A shared latent process generates measurements and their observation masks; learned forward inference supports filtering/forecasting, backward inference supports smoothing/imputation. It jointly trains generative and inference maps using masked energy-score and self-masking objectives. The paper explicitly separates identification of the observed measurement/mask law from identification of missing measurements; full-law identification is for a stated structural subclass. Thus “joint latent simulation + observation inference”, “mask-aware latent state”, or “one framework for forecast and imputation” alone cannot be our novelty. The paper does not establish that every arbitrary missingness mechanism is identifiable. No code qualification or author-result reproduction has occurred here.
- **LatentTrack**, arXiv:2602.00458. [Primary abstract](https://arxiv.org/abs/2602.00458). It uses low-dimensional causal latent filtering and a hypernetwork to generate model weights online without per-step gradient descent. This is relevant to any claim that a lightweight latent update is a new online adaptation capability. Only abstract-level overlap was checked this turn, so detailed assumptions/results remain unverified here.
- **Generative Bayesian Filtering for State Estimation**, arXiv:2607.20521. [Primary abstract](https://arxiv.org/abs/2607.20521). It combines a dynamical prior with a CVAE-induced measurement likelihood in a Bayesian prediction/update recursion. This strengthens the requirement to compare appropriate nonlinear generative filters before calling a learned observation-correction module novel. Full paper/code not qualified in this cycle.

These findings constrain the broad working route, not every possible future mechanism. They do not imply no useful framework can be built. A candidate needs a specific state-learning/correction interaction and a falsifiable advantage over the closest complete method; a common interface or a new label is insufficient. C40's ordinary real-prefix screen is a diagnostic prerequisite, not that interaction.

LIFTS §6.1 additionally reports that its synthetic encoder-calibration term did not systematically improve the evaluated metrics, and uses its coefficient zero in subsequent experiments. This is a prior negative result for a particular auxiliary objective, not evidence that every imagination-based state update is ineffective.
