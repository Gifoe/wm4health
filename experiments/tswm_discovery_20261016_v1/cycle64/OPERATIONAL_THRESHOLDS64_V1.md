# Pre-execution operational screen

This threshold is not a publication significance rule. For the fixed Gaussian SMC subset at P512/32 temperatures, call the ordinary control sufficient on a cell only if all three MC repetitions have normalized Gaussian moment discrepancy<=.1 and terminal-tail absolute error<=.03. A failed threshold is not evidence of new-method necessity: exact Gaussian algebra is already a stronger existing solution, and cost/convergence must be considered. Report every P128/P512 repetition. No budget is selected by test outcomes.

For numerical qualification use oracle precision/conditioning tolerance1e-9 and score finite-difference tolerance1e-6. Exact-target-score DDIM1024 is a numerical control; report its error instead of subtracting it from another method. All solver budgets remain64/256/1024. No learned neural model, real-data intervention result, or top-conference novelty is established by this stage alone.
