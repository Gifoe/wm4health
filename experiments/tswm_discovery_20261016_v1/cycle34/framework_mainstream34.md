# C34 mainstream evidence note: native framework contracts and one bounded lead

Date: 2026-10-17. Frozen scope: `cycle34/RESEARCH_BRIEF.md`. This is an intake note, not an accepted direction or a claim of a demonstrated architecture gap. No training, remote execution, model/data download, or publication was performed. Retrieval used primary arXiv full texts, author repositories and model files. The deep-research citation and adversarial-check protocols were applied. Earlier sources are explicitly background.

## 1. What the recent frameworks actually do

The retrieved frameworks support several legitimate meanings of numerical time-series world modeling. Their native contracts do not justify requiring actions, identifiable physical states, or universal zero-shot weights from every framework. They also do not establish that every useful downstream query follows automatically from a good numerical forecast.

| Verified work and version | Native input / training / output contract | What its evidence supports; practical limit |

Covariates can be historical or known future inputs. | Numerical forecasts on 21 datasets and component ablations. This is an observational forecasting framework; the paper does not make downstream first-passage or general event prediction its demonstrated contract. Its accuracy-versus-directional-response result concerns declared mechanism probes; it does not redefine all observational frameworks as invalid. Its directional-supervision route is outside this note’s proposed lead.

## 2. Release identity and executable evidence

**PathFM is not a verified executable anchor today.** The primary full text’s reproducibility statement says code and model weights will be released. Its paper/arXiv record provides no official model, repository or fps-bench artifact URL. GitHub and Hugging Face API searches did not identify an author-associated release. Search hits for `genbio-pathfm` are histopathology models; `FPS-Bench` hits are video benchmarks. These are unrelated identities. The six metrics are sufficiently specified in Section 4/Appendix D for a reimplementation, but that would not be a native-code reproduction. Unreleased artifacts are an execution limitation, not a scientific gap.

**HEPA has real code, but reported paper results and current code must be separated.** Pin [commit 686deb4](https://github.com/Forgis-Labs/HEPA/tree/686deb403116b99f9a39d3d285c48f5fda12b367), dated 2026-09-25. Its [reproducibility note](https://github.com/Forgis-Labs/HEPA/blob/686deb403116b99f9a39d3d285c48f5fda12b367/REPRODUCIBILITY.md) documents unresolved C-MAPSS paper/code differences and excludes SMAP/TEP/VIX placeholder or degenerate loader outputs from its reproduced table. The release uses variance/covariance regularization, while the paper describes SIGReg. This prevents treating a current-code failure as evidence against the published mechanism without first matching the actual operating point.

The same pinned [C-MAPSS loader](https://github.com/Forgis-Labs/HEPA/blob/686deb403116b99f9a39d3d285c48f5fda12b367/hepa/data/cmapss.py) splits complete training engines by identity and defines failure at the genuine last cycle; official test engines are truncated and must not be relabeled as failed at their last observation. The [BeijingAQ loader](https://github.com/Forgis-Labs/HEPA/blob/686deb403116b99f9a39d3d285c48f5fda12b367/hepa/data/beijing_aq.py) defines PM2.5 exceedance above 250 and uses chronological station splits. It filters out abnormal pretraining rows, joining the remaining rows; a new dynamics protocol should preserve original temporal adjacency. That correction is protocol hygiene, not a publishable mechanism.

**Runnable earlier background:** [Sundial author repository](https://github.com/thuml/Sundial), ICML 2025, links the public [128M model](https://huggingface.co/thuml/sundial-base-128m). At revision `3212e42564493f520593e5414af4367fc4b49226`, [flow_loss.py](https://huggingface.co/thuml/sundial-base-128m/blob/3212e42564493f520593e5414af4367fc4b49226/flow_loss.py#L40) draws standard Gaussian noise and deterministically propagates it through 50 sampling steps. The released configuration has one 720-value output block. For `H<=720`, one call generates a full block then crops it, so sample law is independent of ensemble size in evaluation mode. For `H>720`, [generation line 195](https://huggingface.co/thuml/sundial-base-128m/blob/3212e42564493f520593e5414af4367fc4b49226/ts_generation_mixin.py#L195) feeds the ensemble median into shared history/KV state: these are not independent continued paths, and the continuation law depends on `num_samples`. Restrict this pilot to `H=96`. An explicit-noise wrapper is feasible without forecaster retraining; an independent long-rollout wrapper would be modified inference. The interface is univariate `[batch, context_length]`, not verified native multivariate joint sampling. No weights were downloaded or executed here.

## 3. One constructive needs-evidence lead

**Question:** after a competent generative forecaster has already defined a future-path law, can a history- and query-conditioned proposal over its base noise reduce the *total cost* of estimating rare maxima/first-passage probabilities, including proposal learning and adaptation, beyond classical importance sampling and randomized quasi-Monte Carlo?

This is a finite-budget capability question, not an uncertainty-calibration claim. Fix the generator `Y = G(h, Z)`, with known base density `p(Z)`. For event query `A`, use proposal `q(Z | h, A)` and estimator

`P_hat(A | h) = mean[ 1{G(h, Z_i) in A} p(Z_i) / q(Z_i | h,A) ], Z_i ~ q`.

The integration happens in base-noise space. It does not need an invertible observation decoder or a path-space Jacobian. A defensive mixture `q = epsilon*p + (1-epsilon)*q_learned` preserves support. Correct weighting preserves the chosen generator’s law; it does not make that law true of the data.

The non-obvious interaction is **proposal amortization × expensive conditional path generation × discontinuous query geometry**. A cheap history-conditioned low-rank proposal may exploit repeated queries across related contexts, but a Gaussian mean shift can fail when different crossing times occupy separated noise regions. A high-capacity flow can express those regions while consuming enough pilot samples or training time to lose the advantage. Short distilled generators make plain iid/Sobol draws cheaper, so a method that wins with a slow generator can lose after distillation. This interaction must be measured rather than presumed.

**Closest overlap and bar for differentiation:** this is not new importance-sampling mathematics. [Müller et al., Neural Importance Sampling](https://www.tom94.net/data/publications/mueller18neural/mueller18neural-v4.pdf), 2019, already learns proposal densities for Monte Carlo integration, including primary sample space; [Ryu and Boyd](https://stanford.edu/~boyd/papers/pdf/adaMC.pdf), 2015, already optimize adaptive proposals. PathFM already stratifies Gaussian inputs for small ensembles. A plausible contribution would have to demonstrate amortized query estimation across generators, contexts and query families after these controls, with a measured break-even cost. Merely wrapping a normalizing flow around one sampler is insufficient. Prior components do not prohibit a finite-budget contribution; they make the attribution requirement concrete.

**Small decisive RTX5090 pilot, proposed rather than executed:**

1. Use frozen Sundial-128M and public [fev code](https://github.com/autogluon/fev), with verified [dataset registry revision f71c0ff](https://huggingface.co/datasets/autogluon/fev_datasets/blob/f71c0fff4cf81283a2c43e7f3a73aa4f9826aef8/README.md): `solar_with_weather_1H` (`target`, download metadata 830,505 bytes) and `jena_weather_1H` (predeclare `target_0`, 765,995 bytes). These are a small solar/climate diagnostic, not a claim of broad domain generality. Choose 8 development and 8 held-out histories per task, history 512, future 96, with chronological cutoffs and disjoint future windows sealed before scoring. Use target history only for every method; cache conditioning equally. A second released generator and broader domains are later generality requirements. Earlier search snippets still list removed `solar_1H`; do not trust those stale configurations.
2. Fix max-exceedance and first-passage queries using development-only threshold grids, including a moderate-probability band and a rare band. Do not choose held-out thresholds to make one model fail. Estimate a high-budget reference *under the same frozen model*, with independent scrambles/batches and reported reference uncertainty. Start at 4096 paths and increase only where reference error can distinguish the proposed effect; cap the pilot rather than asserting an unmeasured runtime.
3. Compare iid, antithetic, scrambled Sobol, Gaussian exponential tilt, cross-entropy adaptive mixture, and a competent conditional neural-IS proposal. Count every pilot draw, proposal update and generator evaluation; report wall time and cached-conditioning cost. Test budgets 32/128/512 paths and several query counts per context to expose the amortization break-even. Train any shared proposal on development histories only.
4. Measure repeated-run absolute/RMSE probability error, weight-tail diagnostics, effective sample size, zero-hit frequency and cost. Use the same forecast law and query target for every estimator. This phase evaluates numerical integration. A separate phase against observed futures, including direct event/survival heads and ordinary distributional rollouts, is necessary before claiming better real-event forecasting.

**Stop/rescue rule:** no candidate is accepted from this note. If adaptive classical IS or Sobol matches the learned proposal after full cost accounting, stop the method claim. If improvements require unrealistic numbers of repeated queries, restrict the claim to that workload or reject it. If held-out query estimation improves but the base model is poorly calibrated against data, retain only the integration result and repair or replace the forecasting anchor separately. If a simple fixed proposal is sufficient, that is evidence against the need for a new framework, not a reason to hide the control.

## 4. Answer to the frozen questions

RQ1: the recent evidence includes observational covariate forecasts, shared multimodal latent pretraining, event-time representation learning, structured latent descriptors, and generative path queries. These are distinct contracts, not a single causal-control ladder.

RQ2: a cross-task tension is plausible, but the generic point/marginal-versus-event objection is already addressed by competent path generators and direct event models. HEPA release defects and Pythia/PathFM unreleased artifacts do not prove missing architecture.

RQ3: the surviving constructive lead is narrowly finite-budget, query-dependent inference over an existing path model. Public executable background exists through Sundial/fev; native PathFM execution is currently unverified. Its novelty and useful break-even region remain unknown. A small cost-matched pilot can reject it without further NP/PJM decoder tuning or a hand-built failure generator.
