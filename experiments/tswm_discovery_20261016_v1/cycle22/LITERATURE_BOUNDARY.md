# Framework and novelty boundary for the real-data experiment

The scope is a reusable time-series world-model principle rather than improving one dataset. The current wind-tunnel migration is an independent falsification opportunity for the cycle20/21 lead,not a new proposed framework.

[WorldTS](https://arxiv.org/abs/2609.31162) already learns covariate-conditioned target states with separate numerical target/condition encoders and a frozen-dynamics decoder stage. This experiment uses unchanged native numerical classes at the fixed public revision,with a new data interface and explicit training settings. It cannot be called a reproduction of the original paper's dataset results. A4D-per-token configuration is not a4-number bottleneck because history/condition tokens and RevIN statistics remain available.

[Pythia,2610.05240v1](https://arxiv.org/html/2610.05240v1) already separates cross-dataset predictive representation learning from probabilistic readout adaptation. It initializes from a numerical model,fits contextual corrections against stop-gradient numerical references,and studies matched direct/joint/two-stage controls. Its stated world-model scope is observational forecasting. Therefore generic two-stage learning,independent readout,or reference-guided contextual prediction are established nearby mechanisms. The native model/checkpoint was not located in the limited public artifact screen;this is not proof that none exists. No Pythia execution or from-scratch reproduction is claimed.

[Phys-JEPA,2606.16076v1](https://arxiv.org/html/2606.16076v1) splits predictive states into physical/residual components and applies known physical descriptors and latent transition consistency. Generic physics/residual state separation is already covered. Its use of supplied physical structure differs from discovering unknown roles,but that distinction alone establishes neither novelty nor practical superiority. No native execution is claimed here.

Those two fixed primary HTML snapshots,extracted text and SHA256 are archived in outputs/literature. This is method/interface screening,not a complete proof review. CDL,Denoised MDPs,active subspaces,derivative-informed reduction,ACF and existing source-informed stochastic models remain boundaries documented in cycle20/21.

The key unresolved comparison is role-aware conditional modeling with equal signal availability. If ordinary conditional models and native WorldTS suffice on the real task,the earlier mixed-observation failure does not justify a new general architecture. Action-independent measurements may still be valid forecasting targets;action relevance cannot be substituted for the general definition of a useful world state. Prediction under logged prescribed plans is not paired intervention truth.
