# C75: unpaired observation calibration on two real physical systems

This protocol is frozen before any constructed-shift score. This is a newly designed diagnostic on EMPS and F16 original TRAIN recordings, not a paper reproduction, a causal intervention benchmark, or evidence of changing physical dynamics. No official test MAT is parsed. The independent C71 three-seed run and reserved assessment remain unchanged.

Question: after a monotone scalar observation change, does ordinary inverse-sensor identification through a frozen competent dynamics model already recover conditional simulation? A positive answer rejects the need for a new mechanism on this setting. A negative answer alone does not establish a gap: model misspecification, excitation, ambiguity, capacity and optimization must first be excluded.

For each C74 canonical TRAIN record, source = first40%, calibration = next40%, DEV = final20%. Source dynamics is newly fitted only on source, with per-system pooled source mean/population SD for u/y. Do not reuse C74 first80% coefficients or scaling. Source and calibration trajectories do not overlap. There are no paired canonical/changed calibration outputs available to a learner. Separate physical systems are separate episodes, with independent physical units and sampling rates.

The data generator, outside learner APIs, applies three declared constructed observation functions to source-standardized y: identity x=y; affine x=0.35+1.4*y; nonlinear x=0.25+1.2*y+0.8*tanh(1.5*y). The nonlinear derivative is positive everywhere. These are synthetic observation effects on real trajectories, not measured sensor replacements. The function and its true inverse are withheld from ordinary learners. Known-sensor simulation is explicitly privileged, and cannot establish method superiority. No transfer of one physical sensor across EMPS/F16 units is claimed.

Within calibration, first80% is fitting data and final20% is internal validation. All refit/adapter arms use the same observed (u,x) segments. Source ARX uses lag64, features [1,u[t],u[t-1..64],y[t-1..64]], fixed ridge0.001 times mean non-intercept Gram diagonal. Calibration ARX refit uses the same recipe, with observed x. This is a predictive history model, not a claim to identify physical state.

Ordinary frozen-dynamics calibration minimizes one-step innovation in h(x), where h is a positive-slope affine map or a monotone piecewise-linear inverse sensor with17 calibration-fit quantile knots (uniform quantile fractions0..1). Use exact ARX innovations h(x[t])-sum a_i*h(x[t-i]) = c+sum b_i*u[t-i]. Slopes have broad fixed bounds[0.02,50], offset is unpenalized. Penalize slope deviation from identity with lambda times mean slope-design Gram diagonal. Try lambda [0,1e-6,1e-3,0.1], choose by internal-calibration recursive128-step observed-x MSE; record all options. No canonical calibration labels, known transform family, DEV outputs or physical units enter these fits. Report conditioning, active bounds, extrapolation and exact forward/inverse mapping checks. Offset/scale identifiability is not assumed merely because an optimizer returns a value.

A stronger ordinary nonlinear refit is a residual NARX64 MLP (two128-wide SiLU hidden layers; predicts increment to latest observed normalized x). Features are current/past u and past x as in ARX, omitting the intercept. Normalize observed x using calibration-fit statistics only. Three seeds2026751/2026752/2026753. AdamW lr0.001, weight_decay0.0001; gradient norm cap1;2000 one-step updates(batch256), then500 recursive16-step updates(batch64). Evaluate internal128-step simulation every500 updates; choose checkpoint by that internal score, never DEV. No early stopping or altered budget based on DEV; report all seed outcomes and failures. The provided future-input path is the same across all arms. This is a calibration-data refit, with source information additionally available to adapter arms; no parameter/compute efficiency superiority is claimed.

DEV origins are the C74 origins: cut80%+256, stride256,128 observed history and128 supplied future inputs. Predict all128 recursively without future output reset. Report identity, affine and nonlinear conditions separately for both systems, all records and all seeds. Normalize errors by pooled calibration-fit x population SD; also retain raw observed-x RMSE/MAE. Do not pool across different systems/conditions. Persistence, frozen unadapted ARX, privileged known-sensor ARX, frozen+affine inverse, frozen+monotone inverse, calibration-refit ARX64 and all three NARX seeds are mandatory. No failed-record filtering or prediction clipping.

All predictions, coefficients and weights stay on G. Publish authored code, protocol, compact JSON, logs, all seed/record result tables and the seven research ledgers to Gifoe/wm4health.
