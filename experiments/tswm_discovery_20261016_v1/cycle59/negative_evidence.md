# C59 negative evidence and limitations

Generic mixed-memory architecture necessity is not established: ordinary fixed play/relaxation banks already explain much of the static model's deficit. Their remaining error has no verified noise floor, unknown prehistory and finite feature/order effects. It must not be called a field-wide research gap.

The original periodic tutorial parser subtracts each full H row's mean, picks an H-dependent phase and circularly rolls the full record, then uses periodic interpolation. Those operations can be appropriate for its periodic demonstration but cannot be silently reused when future H is unavailable in a boundary-conditioned deployment protocol. The actual fitted screen uses raw chronological rows and prefix-only H calibration instead. This is task separation, not an accusation about the tutorial.

Only one material and one temperature are available in this sample. Clock-stretching the input while retaining its original H would invent a false response ground truth for rate-dependent physics; no such OOD test was performed. No measurement reset or original device IDs were inferred from filenames. One tutorial material, one temperature, 128 raw rows, one group-disjoint 76/25/27 split. No cross-material transfer, neural-seed stability, identified measurement noise floor, reset-history validation or full official trainer reproduction. All raw arrays were inspected for metadata before this screen; predictive test scores were first computed after the ten selected models were sealed. Overall goal remains active / unachieved; accepted final research directions: zero.
