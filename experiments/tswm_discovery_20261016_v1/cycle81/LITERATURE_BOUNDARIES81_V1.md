# Verified literature boundary for C81

Primary sources were revisited on 2026-10-18. Availability statements distinguish real source trees from unverified executable reproduction. This is a targeted supplement to C79's broader survey, not a claim to have reproduced every paper below.

| Work | Operational overlap | Boundary for this experiment |
| --- | --- | --- |
| [JFR: On the adaptation of recurrent neural networks for system identification](https://arxiv.org/html/2201.08660), 2022 preprint / Automatica 2023; [code and models](https://github.com/forgi86/RNN-adaptation) | Frozen nominal RNN, whole-sequence parameter-Jacobian features, additive correction fit by Gaussian linear regression; offline/recursive variants. | Mandatory future trajectory-feature control. Target CSTR adaptation uses 1024 measurements; a 25-sample initial-state window is not the full adaptation budget. Severe RLC shifts retain a gap to converged nonlinear retraining. |
| [ALPaCA](https://arxiv.org/html/1807.08912), WAFR 2018; [code](https://github.com/StanfordASL/ALPaCA) | Offline learned nonlinear features and readout prior; analytic online coefficient updates. | Learned-feature Bayesian last layers are established. This does not verify arbitrary posthoc foundation features. |
| [Zero-Shot Transfer of Neural ODEs](https://arxiv.org/html/2405.08954), NeurIPS 2024; [code](https://github.com/tyler-ingebrand/NeuralODEFunctionEncoder) | Reusable learned NODE bases; coefficients from observed state increments; residual variant. | No observed derivatives are required. Released implementations integrate bases separately then combine increments; Appendix B also tests summing fields before integration, with lower accuracy. Do not claim those operations as new. |
| [WENDy](https://arxiv.org/html/2302.13271), 2023; [Python code](https://github.com/MathBioCU/pyWENDy) | Weak trajectory constraints and errors-in-variables IRLS for noisy ODE parameter estimation. | Plain weak ridge is a lightweight control, not a reproduction of WENDy's noise handling. C81 cannot establish superiority over WENDy without running it. |
| [FORM](https://arxiv.org/html/2609.38105), Sep 2026; [code](https://github.com/form-robots/FORM) | Weak momentum constraints produce linear coefficient identification over pretrained constitutive bases. | Known mechanical balance and extra physical quantities; not general unknown-dynamics inference, but a direct warning against claiming weak pretrained-basis identification itself as new. |
| [Bayesian Nonparametric Mixed-Effect ODEs with Gaussian Processes](https://arxiv.org/html/2605.13088v2), Oct 9 revision | Population field prior plus subject-specific residual coefficients; context-only coefficient/trajectory adaptation with fixed features and hyperparameters. | Explicit soft-collocation target, not an exact ODE-induced posterior. Public implementation not verified. Close probabilistic precedent. |
| [Bayesian Variational System Identification with Weak-Form Residual Likelihoods](https://arxiv.org/html/2606.14942), Jun 2026 | Noise propagation into weak residuals and parameter-dependent covariance, with conjugate/GLS approximations. | Working residual posterior differs from the trajectory observation posterior. Actual covariance simplifications must be recorded. Code not verified. |
| [LUMA](https://proceedings.mlr.press/v300/park26b.html), AISTATS 2026; [code](https://github.com/azizanlab/luma) | Low-rank linearized network prior and analytic conditioning. | Not a demonstrated general released-checkpoint trajectory-only dynamics adapter. |
| [Linearized Subspace Refinement](https://arxiv.org/abs/2601.13989), Sep 2026 revision; [code](https://github.com/Cao-WenBo/LinearizedSubspaceRefinement) | Posthoc Jacobian correction using reduced least squares, including operator models. | Physics-informed instance adaptation uses known equations/IC/BC, unlike the unknown-law context-only contract here. |
| [Active Bayesian Operator Inference](https://arxiv.org/html/2601.00038v2), Sep 2026 revision; [code](https://github.com/McQLab/ActiveBayesOpInf) | Projection, prescribed polynomial operators, Bayesian coefficient inference and active acquisition. | Known affine-parametric forms, full fields, simulator acquisition; no universal unseen-parameter guarantee. |
| [FIM-ODE](https://arxiv.org/html/2602.08733v2), Jun 2026 revision; [OpenFIM](https://github.com/FIM4Science/OpenFIM) | Released general vector-field inference checkpoint, context conditioning and full-parameter reconstruction adaptation. | Already acknowledges low-data adaptation and new-IC issues. Appendix D.1 explicitly separates train-loss from evaluation-window checkpoint selection. C81 is a new cross-system screen, not rediscovery of this limitation. |

No C81 result is evidence of a calibrated Bayesian field posterior. Features and the native prediction both depend on the target context. Weak-design and response noise are coupled. Ordinary ridge remains a valid algorithm to test, but Bayesian terminology would require an explicit working likelihood or a justified conditional/empirical-prior construction.
