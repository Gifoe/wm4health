# Feasibility decision, fixed before held-out scoring

All results remain exploratory synthetic mechanism evidence. The following numeric rule limits interpretation; it is not a statistical claim of broad model superiority or a final-research-direction acceptance gate.

Use the preregistered h=20 changed-plan conditional-mean effect MSE, mean over the three neural seeds. Let N be native error, C a specified existing control's error, P the deterministic proper-control error for the same sensor. If N-P <= .005 (physical state coordinates have invariant variance one), there is no actionable native deficit by this feasibility rule. Do not turn a very small or negative gap into a ratio.

Otherwise report closure fraction (N-C)/(N-P), without clipping or selecting a winner. An existing stochastic normalizer control counts as a repair in this small setting if it closes at least 80% of the native-to-proper gap in the nonlinear sensor case, improves on native in all three paired seed comparisons, and does not worsen linear-sensor mean error by more than .005. Report all three independent/running controls, not just those that pass. Full-reference repair is reported separately with its greater reference cost; it is an attribution control, not evidence that a small-batch adaptation solved the resource question.

Failure to pass is not proof of a new gap: optimization, running-estimate tracking, finite-data approximation and representation fitting must still be assessed. Passing only eliminates a proposed necessity for a new correction in these two systems. Either outcome leaves real-system generalization, practical arbitrary-sensor learning and novelty outstanding. No final direction can be accepted from this gate alone.
