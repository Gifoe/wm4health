# C69 primary-source boundary

Retrieved2026-10-18. Focused audit, not an exhaustive six-month review. Read depth and execution are separated.

- [Rufolo et al., in-context system identification](https://arxiv.org/html/2610.13411), Sec4/6 and source notebook:400-context ensembling, cached memory,30 query initialization points and100 predicted points define the executable baseline. The original benchmark task family is simulated output under given inputs. The public paper and pinned repository PDF both report WH RMSE.0014, Tanks.429 and CED[.068,.055]. This cycle is an explicit reproduction attempt, with current-loader versus paper-prefix protocols reported separately. No upstream meta training was reproduced. Code and weights are actually executed; the paper-table mapping remains incomplete.
- [Author source/release](https://github.com/PuraFilippo/sysid_benchmarks/releases/tag/v0.1) and [release-to-head comparison](https://github.com/PuraFilippo/sysid_benchmarks/compare/v0.1...master): only README and a PDF changed after the weight release. This rules out an architecture-code change over those two commits as the simple explanation. It does not certify exact checkpoint-to-table correspondence.
- [Official nonlinear benchmark loader](https://github.com/MaartenSchoukens/nonlinear_benchmarks) and primary [WH](https://www.nonlinearbenchmark.org/benchmarks/wiener-hammerstein), [Tanks](https://www.nonlinearbenchmark.org/benchmarks/cascaded-tanks), [CED](https://www.nonlinearbenchmark.org/benchmarks/coupled-electric-drives) pages establish numeric sources and split/initialization contracts. Loader functions and containers are executed via exact safe AST extraction; downloader, SSL fallback and cache deletion are not executed.
- [dynoNet author baseline](https://github.com/dariopi/dynonet_baseline), [underlying library](https://github.com/forgi86/dynonet): exact architecture, scalers and apply path plus three released target-trained artifacts execute. Their training/selection provenance is not independently reproduced. This is a separate information group from the synthetic-pretrained contextual model.
- [Bayesian Context Aggregation](https://openreview.net/forum?id=ufZN2-aehFa) is older direct prior art; current OpenReview challenge prevented rereading its full paper this cycle. [Exploiting Inferential Structure in Neural Processes](https://proceedings.mlr.press/v216/tailor23a.html) provides structured probabilistic aggregation. Existing C25 evidence also rejects relabeling a generic posterior update as a new framework. No new execution of these NP methods is claimed.
- [Learning Nonlinear Systems In-Context](https://arxiv.org/html/2602.07173), abstract/method only: separate signal representation and system behavior with synthetic-to-motor adaptation is another adjacent formulation. No author implementation or data execution was verified this cycle; an unverified code link is not a research gap.

Known expert-error correlation and estimator-versus-predictive variance must not be marketed as a new discovery. Pointwise moments do not define a joint simulated trajectory law. Exact research novelty remains unestablished.
