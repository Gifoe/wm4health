# Post-screen ordinary weak-regression control

The initial screen was independently verified: all8 Duffing conditions passed with a validation-selected existing repair. The qualified first Brusselator seed passed no-change and observation-only conditions, but its dynamics-only and joint conditions failed for all tested families. Its second neural source remains unqualified, and that seed's EVAL has never been generated. These failures are not yet a new research gap.

Competing explanation: fitting noisy one-step differences introduces ordinary identification error that becomes larger after changing the chemical dynamics. Test standard weak-form continuous-field regression, not a new method. Use the same source/calibration data and ordinary polynomial3/RFF128 features as before. Source and target are observed only in their respective sensor coordinates; no true equation, unknown sensor formula or analytic derivative is given to fitting.

Weak test function on a window of8 or16 intervals: psi(s)=16s^2(1-s)^2, s in[0,1]. Use integration by parts: integral psi*phi(y,u)*W=-integral psi'*y. Evaluate integrals intervalwise by Simpson quadrature with linearly interpolated observed states and the actual held command on that interval. Normalize rows by integral psi. Stride4. Fit source coefficients by ridge1e-6. Before target fitting, check source VAL H32/H128 against the original0.15/0.35 gates separately for every feature/window option; exclude unqualified options.

For each qualified option fit target coefficients from target TRAIN, ridge{1e-6,1e-3,0.1}, source-prior strength{0,1e-3,0.1,10}, identical to the previous ordinary grid. Simulate learned fields using RK4, dt0.05. Select one primary candidate by target VAL H32 and a separate diagnostic candidate by target VAL H64, both before EVAL generation. This explicitly checks ordinary estimator and selection-horizon explanations. Do not select on EVAL or label the control a new method.

Run all four Brusselator change conditions for both original seeds. First-seed results are post-screen attribution, not confirmatory new-method gains. The second seed's four EVAL conditions are first generated only after their weak-model selection seals, providing an unopened test of this ordinary control. Preserve and independently check equality of all overlapping reference trajectories and initial measurements to the original experiment. The unqualified second neural source is not scored or retrospectively qualified by this control.

Use the original trajectory and action-response metrics, guards, noise and thresholds. Retain every candidate, selected coefficient, raw prediction and failure. If this standard control solves the failures, do not promote them to a novel mechanism. If it does not, assess support/coverage, sparse-update priors, training objective and finite-data identifiability before claiming a gap. No baseline neural hyperparameters or old selections are changed.
