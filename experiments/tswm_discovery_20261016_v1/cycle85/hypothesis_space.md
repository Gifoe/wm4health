# What this screen can distinguish

* H0: existing output-space regression or joint adaptation is sufficient for the anchored fully observed subcase. Test the presealed validation-selected existing repair against independent trajectories and matched action responses. Report casewise evidence rather than a universal claim.
* H1: a frozen-dynamics aligner alone must handle genuine dynamics change. This is not an appropriate requirement for that baseline; failure is not a new gap.
* H2: a poor transfer score is caused by an inadequate source simulator. Source-only qualification identified this issue for the initial Brusselator fits. Capacity and longer-rollout source training are controls; those changes are not scientific contributions.
* H3: lower trajectory error necessarily implies better action-response fidelity. The two metrics are measured separately. A difference is descriptive unless a new mechanism survives ordinary repairs and attribution controls.
* H4: results on these small fully observed systems establish generality for partially observed or high-dimensional world models. Not tested. Additional state inference, uncertainty, observability and competent latent-state baselines would be required.

No endpoint is a guessed label for which latent component physically changed. No counterfactual metric applies identically named but physically different latent-state interventions. Inputs are the same explicitly specified physical commands in all comparisons.
