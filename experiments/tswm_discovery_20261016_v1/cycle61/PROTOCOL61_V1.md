# C61: qualify a learned existing explicit-duration model

Question: does an existing learned HSMM already implement useful posterior remaining-life forecasts under noisy, unlabeled observations? This is a prior-art exclusion experiment, not a proposed new world-model framework or a paper-table reproduction. A positive result for the existing method removes support for a generic duration-memory novelty claim in this controlled family. A failure does not establish a field-wide gap.
