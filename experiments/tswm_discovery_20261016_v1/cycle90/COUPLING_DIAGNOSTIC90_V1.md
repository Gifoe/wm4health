# Prospective CAL-only coupling falsification

Frozen while the first full-budget generator is still fitting, before its CAL competence screen. This is a mechanism-diagnosis experiment, not a native OneWorld reproduction or a proposed new architecture.

Train one ordinary MLP classifier from raw standardized trajectories plus actions/family to nine TRAIN mechanism identity classes. These identities are supervision only; no physical parameter values or hidden IDs enter the classifier at deployment or the generator at any time. Randomly permute the nine class names using seed20269061, so numeric class order conveys no physical ordering. Input is all4x72 native features, two hidden128 SiLU layers, nine logits, seed2026906, Adam1e-3, batch256,10000 updates, lr multipliers.1 at7500/9000. Select steps0/1000/3000/6000/10000 by CAL classification cross-entropy only. Require overall CAL accuracy>=.9 and macro accuracy>=.8 before interpreting learned-semantic coupling. Record all class accuracies and the known TRAIN class prior. This has extra mechanism-group supervision comparable in type to shared-world pairing; it is not an unsupervised learned-physics claim.

If the full-budget native generator and interpreter both qualify, run a CAL-only mechanistic comparison with128 native samples for the same32 CAL action plans per family. One pool uses independent random streams per action; another resets the same entire reverse-diffusion noise stream for each plan in a four-plan group. Compare independent pools, common-noise pools, established ensemble-copula/rank reordering of independent pools using (predicted class, original sample index), and a learned-class shared-world Bayesian reweighting control. Do not choose a method or hyperparameter from EVAL.

For the reweighting control, let p_b(c) be the empirical class frequency for plan b and pi(c) the empirical TRAIN prior. Put shared-class mass proportional to product_b p_b(c)/pi(c)^(K-1), K2/3/4, with uniform independent sampling among each plan's members in the selected class. Enumerate the nine class masses exactly. This is the correct shared/independent ratio in the ideal categorical posterior case; it need not preserve actual imperfect generator marginals. It is an established Bayesian control, not OneWorld's native continuous-time guidance. Cases of no shared support are explicit failures, never filtered.

Measure per-plan changes in trajectory/sample weights and fixed-anchor changes when adding plans; score the resulting per-plan empirical laws against the true nine-world distribution using energy score and two real trajectory-risk events: maximum absolute state-x exceeds.75, and final state-x exceeds.25. These thresholds are frozen before reading CAL coupling outcomes. A changed prediction is not automatically worse: improved calibration can compensate model error, as earlier C25 evidence already showed. Strictly preserving a bad base forecast is not a universal goal.

Measure physical alignment independently of learned class agreement, using nearest exact reference trajectories and reporting physical residual as well as agreement; class agreement alone cannot certify shared true physics. Keep the distinction between discrete-reference bin alignment, shared latent indices, and exact shared continuous physical parameters. Ensemble reordering preserves all empirical single-query laws exactly, and common-noise/rank constructions can be defined from query-independent streams. These are old positive controls. No novel optimal-transport, Gaussian-coupling, projectivity or probability-calibration theorem is claimed.

If the native generator remains unqualified, no raw-trajectory coupling failure is scientifically attributed. Complete and retain the classifier/ordinary baseline results, but do not open EVAL. This experiment may falsify the need for a new method in the controlled setting; it cannot by itself establish a final top-conference research direction.
