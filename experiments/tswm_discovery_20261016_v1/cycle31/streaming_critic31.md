# C31 独立批评：问题成立，算子增量尚未成立

2026-10-17；方法学/反例视角。独立检索一手论文与公开代码；未运行模型、未训练。问题收敛为：**未知边界下，何时已有足够证据值得更新转移规律；有限计算应保留哪些解释？**这有实际价值；泛称“分离状态与动力学”没有新意。

## 可识别性：先定义允许恢复什么

局部短窗线性化并白化后，残差为

\[
e=O\delta x_\tau+J\delta\theta+\epsilon,\quad P_\perp=I-OO^\dagger.
\]

只有 \(P_\perp J\delta\theta\) 超过噪声，参数改变才有超出未知初态的证据。单步可令状态冲击等于参数变化的效果；低激励、短窗或不可观测时，多步也可能无区别。此为本笔记推导，不是新定理。若该项为零，任何归因准确率都受先验支配，正确行为是保留不确定性。

还须固定观测映射/采样协议；否则 latent 坐标变换、未知输入、传感器漂移均可伪装机制变化。白噪声状态与白测量噪声只呈现方差之和时，Q/R 根本不能分别识别。用不同幅值制造“易识别噪声类”会虚增成绩。

## 最危险普通修复

[切换 SSM](https://www.cs.toronto.edu/~hinton/absps/switch.pdf)已容纳类型隐变量；[dual Kalman](https://papers.nips.cc/paper/1202-dual-kalman-filtering-methods-for-nonlinear-prediction-smoothing-and-estimation.pdf)已联合适应状态与参数；[BOCPD](https://arxiv.org/abs/0710.3742)已维护未知 run length。最强组合是：状态冲击/参数重置/噪声改变/无变化分支，分支内联合或 dual EKF/UKF，外层 IMM/截断 BOCPD；再给 robust likelihood、窗口遗忘及同分布混合事件训练。单一双滤波器失败只证明单峰近似不足。

唯一值得筛选的机制是**延迟合并原因分支**：固定短滞后保留边界和原因的联合后验，仅在状态边缘化后的累积预测似然支持时提交参数改变。上式投影只是该边缘化的局部 Gaussian 表达；lag/beam 保留已经属于 GPB/截断切换滤波。它可作正控制，现阶段不能包装新架构。真正尚待实测的是：非线性部分观测时，同预算近似是否留下可压缩的计算差距。

## 唯一最小筛选与撤销线

自主推断筛选，非原生复现：二阶振子与弱非线性摆两个已知方程族；仅位置带噪可见，速度、参数、变化类型/时间仅评分。所有方法同知方程族和观测器，不知实例参数。每条256步、随机边界80–160；分开生成状态冲击、参数改变、R改变、输入分布改变、无变化及共现。全体共享预先公布的 PRBS 输入计划（包括预测窗），另设低激励负控制；固定采样且先匹配事件创新强度。

比较窗口 dual UKF、上述 IMM、BOCPD-UKF与lag保留；每步4/16/64次转移或Jacobian评估，同时报告真实墙时、内存及全部离线调参成本。共同训练/校准数据必须含全部事件类型；不得给候选额外真状态、边界或未来输入。用独立系统划分调参/测试，各至少20系统并按系统配对区间。

主评分是未来1/8/32步 NLL 与状态冲击后误改参数的损害，另报原因后验校准和拒绝归因率。离线更大预算后验仅为上界。若普通 IMM/BOCPD 在可识别组已闭合差距，或优势只来自额外历史、原因标签、弱基线训练、低激励组，则撤销；若lag方案只赢立即合并IMM，也仅证明保留历史有效。只有跨两族存在同预算余差，才值得研究其近似压缩，当前不接受方法方向。
