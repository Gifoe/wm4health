# 最新用户纠正：时间序列 world model 框架

研究对象是时间序列 world model 的通用建模问题，WorldTS 为问题层次与框架贡献的参照。具体研究 idea 由 agent 根据文献和实验自主选择。单数据集调参、某个数据集专有模块或只修一个实现错误，均不足以完成任务。

“通用”指建模机制与贡献可以在不同时间序列系统/数据集上复用，并不要求一个共享 checkpoint 零样本覆盖全部领域。WorldTS 本身包含按数据集训练的条件预测设置，不能额外要求每个候选必须是 foundation model。

不预先强制动作条件、Loop、LLM、物理状态可解释、严格因果反事实或在线变化识别。以作者实际任务合同评价现有方法；未声称因果干预的方法，不因缺少因果保证而自动判作失败。未来状态预测、状态表示学习和条件信息如何作用于演化机制，都可构成框架层面的研究问题。

后续候选必须说明：跨系统可复用的问题和机制是什么；为什么不同于已知方法；哪项公平且可证伪的实验能直接检验。数据集只承载证据，不定义研究贡献。允许负结果与撤销候选，不强行宣布创新。
