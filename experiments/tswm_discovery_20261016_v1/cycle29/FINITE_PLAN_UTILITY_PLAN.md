# Finite candidate-plan utility, frozen before C29 model TEST inspection

Purpose: determine whether simulation errors affect a concrete decision on the same independent physical worlds. This is a predeclared secondary evaluation, not a new benchmark, controller, intervention-identification claim, or new model. No new predictions, training, hyperparameters, or systems are selected from the scores.

Use every existing LTI and WH test world, every model/ablation/reference, every training seed, and all four already generated candidate plans in their fixed order: factual, zero, step, pulse. Targets are the three fixed constants -1,0,+1 in the benchmark's fixed-reference output units. Horizons are32,64,128. For each candidate j, predicted cost is mean((predicted_y-target)^2)+0.01*mean(known_future_u^2). Choose argmin with NumPy's fixed first-index tie convention. Cost uses only the predicted future and the known proposed input. The model never receives true future outputs or oracle costs.

Score the chosen plan with the corresponding noise-free physical future, using the same target and input cost. Oracle is the best of these same four plans under noise-free truth, not the optimum over all possible controls. Regret is chosen true cost minus that finite oracle cost. Report oracle-choice fraction, mean regret, world median/upper quartile regret, and actual costs; always-zero and always-factual are explicit decision baselines. Normalize regret only descriptively by the mean always-zero true cost, with raw regret primary. No weak-regret cases are removed. Fixed-reference unit metadata belongs to the benchmark protocol, not target-dependent calibration.

Report all3 targets and3 horizons by family and model. Aggregate equally over targets inside each physical world; then average worlds, retaining all training-seed means and variability. The primary paired contrast remains compiled64 versus conditional128, with all three individual seed differences. Descriptive crossed world/seed bootstrap uses2000 fixed draws; only3 training seeds limit inference. Do not choose targets or utility weights after seeing which model benefits. The coefficient0.01 is an illustrative fixed engineering objective, not tuned to an application or claimed universally meaningful.

Actual observations contain shared measurement noise; decision scoring uses the saved noise-free trajectories. It estimates performance in the declared known-input simulator, not real observational counterfactual truth, population causal effects, or safety. The four candidates are coarse. Strong performance can falsify a claim of practically consequential failure on this task; poor performance alone does not establish an unresolved gap. Check training, capacity, invocation, source objective, and ordinary identification controls before a structural interpretation.
