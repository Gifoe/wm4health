# Adjacent lead, not an accepted direction or a new campaign

Do not extend C88's ordinary causal-indexing comparison to manufacture architecture novelty. A different, concrete question surfaced from a primary-source read while the registered fits were running: **does an edited context correspond to one reusable changed dynamical mechanism across different action queries and initial states?** This is distinct from action-prefix timing and from whether an edit merely makes a rollout distinguishable.

## Verified source and scope

[DALI, NeurIPS2025 / arXiv2508.20294v3](https://arxiv.org/html/2508.20294v3), sections6.3 andD.1, ranks latent-coordinate edits by an ensemble classifier distinguishing edited from factual imagined trajectories, then interprets selected passive/control examples as physically plausible gravity/string or actuator changes. Its setup has episode-fixed hidden context. Its reported shallow integration supplies context to the observation encoder, with implicit recurrent propagation. These establish an explicit context-editing claim worth testing, not proof that the actual learned models fail. [Official code](https://github.com/frankroeder/DALI) is released in JAX; no checkpoint link was located in the README inspected here. No training or checkpoint reproduction was performed for this lead.

Inference from that source: distinguishability AUC by itself does not test whether a single changed mechanism explains the edited outputs under other actions/roots. AUC may be high for arbitrary model drift. This logical insufficiency is elementary and is **not** itself a novel result. The empirical question requires native, trained, adequately accurate models and real simulator comparisons.

## Small discriminating test if this lead survives closest-work review

For a fixed source context and one frozen edit, fit a single simulator parameter vector to edited model branches on a calibration subset of roots/actions. Evaluate that same parameter vector on independent roots/actions, without refitting per query. Preserve the physical initial state and all nonedited mechanisms. First require accurate unedited simulation; otherwise a semantic-edit verdict is uninterpretable. Physical parameters are privileged diagnostic labels for this existence test, not inference features granted to learned models.

Compare intended edits with equal-norm random directions, no edit, source-context-manifold projection/nearest-neighbor controls and a parameter-conditioned oracle. If a plain projection or already context-conditioned model solves the issue, do not call its reuse a new mechanism. Distinguish changing a dynamical parameter from changing the current physical state. Any native task-variable edit must retain initial-state fidelity.

Scope: relevant to models that explicitly expose or claim mechanism/context edits. Actionless forecasters without such an interface are not failures on an unclaimed task. Closest work on causal representation learning, counterfactual latent-state carriers and interventional dynamics must be read before any novelty assertion. The search lead arXiv2608.15156 could not be retrieved as HTML in this turn and cannot be treated as verified full-text evidence or used to veto the direction from its title.

Current status: needs native checkpoint feasibility, closest-work differentiation, and actual cross-query simulation evidence. Accepted research directions0. No new architecture or learner campaign is authorized by evidence in this note; ordinary user-authorized research remains available, but a new expensive run should first have a discriminating contract.
