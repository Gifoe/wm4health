1. Native A generation completed and saved its data, then the provenance writer
   failed because the new outputs directory was absent. The writer was corrected,
   existing generated bytes preserved and validated, then provenance recorded.
2. The first training adapter omitted the native initialization namespace `init`.
   It failed before the first training update. That terminal process/log/plan are
   preserved under `outputs/child_native_A`; the corrected execution uses the
   separate `child_native_A_r1` directory with unchanged scientific settings.
3. The first innovation reconstruction incorrectly substituted conventional
   LeakyReLU for a native helper whose actual body is `return D`. Its rank7 result
   and failed expected-rank assertion are not evidence of native innovation
   independence. Reconstruction was corrected to the pinned generator's actual
   identity helper. The native source and generated data were not changed.

These are adapter/audit errors, not scientific model failures. No failed
calculation is silently substituted for an accepted experimental result.
