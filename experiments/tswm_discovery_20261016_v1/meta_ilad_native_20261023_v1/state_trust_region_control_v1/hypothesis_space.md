# Explanations still separated

A simple unconstrained-update problem receives limited support: ordinary variance-scaled constraints reduce some harm magnitude. That mechanism alone is insufficient for all recorded cases. Encoder variance calibration, model/observation mismatch, finite-prefix ambiguity and richer probabilistic inference remain competing explanations. A per-environment CV mean optimum is not an individual-query safety certificate. Existing assimilation methods must be compared before any new mechanism is inferred. Query futures never select the reported strength.
