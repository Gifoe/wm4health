# Current source and innovation boundary

[Meta-iLaD](https://arxiv.org/abs/2610.27180v1) is direct prior work on jointly identifying states, environment variables and dynamics. Its [current official source](https://github.com/GoForIt-YYB/Meta-iLaD/tree/3d47140f18262628d252858c3efdfe2ad1e21a86) released executable code and checkpoints after earlier code-soon notes; its MoCAP branch is refined only. A new latent-context idea must compare assumptions, grouping information and identifiability rather than repeat this problem statement. [PyTorch reproducibility guidance](https://docs.pytorch.org/docs/2.14/notes/randomness.html) already covers the general seed/device limitation. [Existing intervention/representation boundaries](../mechanism_edit_20261023_v1/MECHANISM_NOVELTY_SCREEN_V2.md) also remain relevant. No generic consistency, low-rank editing or separated-context framework is accepted as novel.
