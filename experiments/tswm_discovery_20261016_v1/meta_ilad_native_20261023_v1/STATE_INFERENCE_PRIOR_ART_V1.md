# Direct prior art for the observed inference/forecast tradeoff

Checked2026-10-23, targeted quick literature check for the existing rolling-origin failures. Public method titles and keywords only; no private results were sent in search queries. Primary sources below support the stated facts. None of these papers is newly reproduced by this check.

| Work and source status | What was actually read | Consequence for this experiment |
| --- | --- | --- |
| [AIKAE, TMLR May2025; arXiv2503.12930v2](https://arxiv.org/html/2503.12930v2), Frion et al., method+experiments | Section6 and Table2 directly discuss latent initial-state fitting that reduces assimilation cost while worsening future prediction; their KAE example overfits while the compared invertible models do not show that behavior in the reported task. | The observed prefix/future conflict is not a new problem. Our synthetic-image state fit does not reproduce their satellite study or prove their remedy insufficient. |
| [VAIKAE, arXiv2609.37435v1, Sep29](https://arxiv.org/html/2609.37435v1), Frion et al., method+experiments preprint | Sections2.3,3.3,5.2 discuss latent assimilation, including optimization of an initial Gaussian's mean/variance and a CRPS objective. | Merely adding uncertainty-aware latent assimilation or fitting a distribution rather than a point is not our innovation. It has not been executed here. |
| [Mattern, Edwards and Moore, Monthly Weather Review2018](https://repository.library.noaa.gov/view/noaa/48303), method+application; [primary full text](https://repository.library.noaa.gov/view/noaa/48303/noaa_48303_DS1.pdf) | The paper distinguishes fit to assimilated observations from subsequent forecast skill and adjusts background/observation errors using ordinary assimilation diagnostics. | Prior strength and observation-error treatment are standard explanations to test before attributing a new dynamics defect. This is not the implementation used in our control. |
| [LDNet variable initial conditions, arXiv2610.08475](https://arxiv.org/abs/2610.08475), Oct6 preprint | Author abstract: initialization from early observations via auto-decoding or meta-learning. | The broader proposal to optimize a world model's initial latent state is already covered. Abstract-level screening only; no new code execution. |
| [T2-z, arXiv2610.22364v1](https://arxiv.org/html/2610.22364v1), Oct15 preprint | Previously checked direct environment-latent optimization with the world model frozen. | State-only fitting differs from environment-latent adaptation, but neither generic operation is new. Existing check remains in[the earlier boundary](CONTEXT_REFINEMENT_PRIOR_ART_V1.md). |

Source quality: archival journal/primary author papers prioritized; no excluded venues or AI-generated reviews used as evidence. OpenReview's current forum/PDF endpoint presented a browser challenge; the public author arXiv version was read instead. The Hereon bibliographic page contains an inconsistent volume field, so that field is not copied or relied on; TMLR/date come from the author PDF header.

This narrow check gives high confidence that the **generic phenomenon** and ordinary regularized/variational responses have prior art. It gives no basis to say every learned nonlinear partial-observation model is solved. A remaining research candidate would require a distinct task or mechanism and independently demonstrated failure despite adequate ordinary inference controls. Presently none is accepted.

The current control is only a variance-scaled proximal penalty around an encoder estimate, calibrated by leave-one-out predictions inside the already available context library. Because that estimate already used the prefix, it is not an independent Bayesian prior and no calibrated posterior guarantee is claimed. Selection uses complete support episodes that were already allowed; original-query future outcomes remain excluded. Improvement, if observed, is an ordinary attribution result with extra inference compute.
