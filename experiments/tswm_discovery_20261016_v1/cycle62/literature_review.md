# Literature and novelty boundary

[PRO-DYN source](https://github.com/ARBrachet/PRO-DYN/tree/733d986d349e9e71ded5d9cdeeeed8d3323d83b4) supplies the exact model variants and training defaults. [The authors’ project](https://arbrachet.github.io/PRO-DYN/) defines temporal propagation blocks in forecasting; the code experiment here is not a numerical reproduction of the complete paper tables. Original upstream files remain unchanged and are recorded by Git blob/SHA256, but are not republished because this pinned repository contains no license file.

Subsystem reuse is already studied in [Neary and Topcu](https://arxiv.org/abs/2212.00893) and [input-output subsystem identification](https://arxiv.org/abs/2411.05730). [C-PHAST](https://shubham-bhardwaj.com/cphast/) also explicitly exposes block recomposition and target-specific wiring. These are source-scope checks, not executed baselines or proof that every partially observed composition problem is solved. Generic module composition is therefore not accepted as a new idea.

No new research direction is established. At L=H=96 PRO and DYN are exactly the same computation after parameter-key renaming; same-RNG CPU forward and gradients matched exactly in training/evaluation modes. PRO has three completed training seeds; DYN has two auxiliary duplicate fits. This corrects the earlier interpretation note about different modified paths. Four fits use native window copies and four qualified cached copies; three formal attempts crashed. All sealed fits are scored on the native CPU inference path. Do not call a rank change or PRO/DYN duplicate differences a novel mechanism. Existing multistep system identification, state-space simulation and dynamical-system reconstruction are necessary next controls if a residual failure merits further study.
