# C62: native PRO-DYN reproduction and longer-rollout screen

Scope frozen before new training/test predictions. This is a partial original-protocol reproduction on ETTh1 followed by an exploratory deployment audit, not a new method and not a causal intervention experiment. ETTh1 was used in earlier project cycles; it is not an untouched confirmatory domain. No research direction is accepted from this screen alone.

Question: with the authors' ETTh1 horizon-96 settings and unchanged native training/forecasting components, does the relative performance of Informer, Informer_PRO and Informer_DYN change when the same trained forecast is composed for 192/384 steps? The ordinary finite-horizon forecasting problem and autonomous resimulation must be reported separately. Poor extended forecasts alone are not a research gap.

Source: ARBrachet/PRO-DYN at 733d986d349e9e71ded5d9cdeeeed8d3323d83b4. Exact original file Git blob hashes are in PINNED_SOURCES62_V1.json. Use upstream models, training adapter, validation, data provider, time features, early stopping, optimizer, schedule and batch forecasting unchanged. Namespace loading bypasses unrelated eager package imports. A runtime numpy.Inf=float('inf') alias only restores the removed NumPy 1.x constant. These compatibility choices must be recorded; do not claim the entire TFB CLI/reporting stack was reproduced.

Data: existing ETTh1.csv must match the official ETDataset pinned Git blob and size. Preserve source column order and date index. Total train+validation fraction .8, within it training fraction .75, as in the authors' rolling configuration. StandardScaler fits training rows only. No future measurements enter decoder inputs. Calendar time features are known in advance. All full arrays, weights and raw predictions stay on the authorized G disk. Publish authored scripts, source receipts and compact metrics only; do not mirror unlicensed upstream source.

Nine fits: three arms x seeds 2021/2022/2023. All use official horizon-96 ETTh1 scripts: L=96, H=96, d_model=32, d_ff=128, e_layers=2, d_layers=1, heads=8, factor=1, dropout=.1, norm=true; other defaults from native TransformerConfig. Native Adam lr=1e-4, batch=32, maximum 10 epochs, validation patience=3, native type1 schedule. Select by native validation MSE only. Save selected and terminal weights. Run fits sequentially, never restart a timeout without checking actual process state.

Qualification before campaign: source/data hashes; native imports; finite forward/backward for each arm on training-only data; source data provider label prefix equals observed input tail; prediction has shape [B,96,7]; demonstrate decoder construction excludes future target values. Qualification uses one backward pass per arm without an optimizer step and does not enter scientific training counts.

Scoring after all fits sealed: (1) original H=96 rolling-origin point metrics on every permissible test origin, stride 1, batch32; (2) native block rollout to 384 at common test origins stride96, and the first96/192/384 values scored at identical origins. Use three pre-fixed inference RNG streams, since native ProbAttention draws query indices even during evaluation. Their variation is algorithmic randomness, not posterior uncertainty. Primary scores use train-standardized MSE/MAE, plus channel-wise metrics and finite counts. Full official-table numerical reproduction is not claimed: only three selected arms and one horizon/dataset are run.

Ordinary controls: persistence, known daily seasonal-24 repetition, and direct multioutput ridge L96->H96 composed recursively. Ridge alpha in {1e-4,1e-2,1,100} selected by validation H96 MSE only, using native train/validation boundary and train-only scaling. Ridge is not an execution of an upstream model. All selected controls are evaluated on the same origins and metrics.

Independent checks: recompute compact metrics from retained prediction arrays; verify source/checkpoint/prediction hashes and no test targets accessed by model call paths; for one training-only probe per arm compare native batch rollout to an independent loop around the unchanged model with identical RNG stream and calendar marks. No observation feedback is permitted within free rollout. Overlapping test windows and one measured system do not supply independent population replicates; report seed spread and descriptive trajectory metrics without iid-window significance claims.

Disposition rule: if an ordinary control removes the observed deficit, keep that negative evidence. If relative rankings change, investigate training horizon, point-score objectives, rollout interface and existing dynamical-system reconstruction methods before proposing an architecture. Do not tune a new loss or select an evaluation horizon after viewing test results. This experiment can justify a next falsification test; it cannot by itself establish novelty or top-conference potential.
