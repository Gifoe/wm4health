# Additional prior-art boundary

[Probabilistic in-context system identification,2610.13411v1](https://arxiv.org/html/2610.13411v1) already combines cross-system prediction, recurrent context patching, uncertainty-weighted context ensembling and input-distribution adaptation. Equation8 uses a temporally factorized Gaussian, not a posterior sampler over dynamics. The official ensemble notebook combines predicted means with inverse-variance weights; its individual-context uncertainty plot is not a measured ensemble coverage failure. No such failure is claimed here.

The native generator standardizes using statistics of the generated sequence, including portions later designated as query. [FIM-SDE,2502.19049v3](https://arxiv.org/html/2502.19049v3) already estimates drift and diagonal diffusion from noisy, irregularly sampled trajectories across systems. Its loss targets posterior-mean functions, with a learned scalar uncertainty proxy. It is not a sampler over full function posteriors. This distinction defines a comparison contract; it is not evidence of an error in the capability the method actually claims. No FIM execution or weight download is claimed.

These sources reject generic novelty claims about inferring a dynamical system from history, adding a variance head, or introducing cross-system pretraining. They do not prove every finite-resource reusable-belief problem solved. A remaining contribution needs evidence beyond ordinary generative state-space inference, functional neural processes and calibrated residual/covariance postprocessing.
