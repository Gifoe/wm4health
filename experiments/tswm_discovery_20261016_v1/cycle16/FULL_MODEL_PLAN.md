# Full learned-model relevance gate

Objective: general time-series world-model research, not tuning one dataset. Cycle15 found an admissible native moment approximation, but ordinary joint Gaussian propagation solved the witness cheaply. A new method is not accepted. This cycle tests whether the relevant context/covariance channel matters after actual end-to-end learning.

Type: new conditional forecasting experiment using native MTS3/HiP-RSSM components from official MTS3 source `ab971c0ec43df7664c4b727ca69d5b8dd0cab5da`, transferred to existing public numerical WorldTS benchmark data. Not an original MTS3 paper/data reproduction. No point forecaster is required to implement a probability or causal-intervention interface. Conditions are six deterministic calendar features, not physical actions or authenticated interventions. The two raw forecast-covariate columns are excluded because issuance-time provenance for their future values is unavailable. Do not rank these results against the original WorldTS information protocol.

First pilot: NP, seed2021, native MTS3, canonical latent_obs_dim30/time-scale75/hidden sizes. A HiP-RSSM pilot or further datasets/seeds require an informative next discriminator; there is no automatic model-count target.

Data: existing long-format public NP CSV in the earlier baseline folder; verify SHA256 against the earlier sealed provenance. Reorder OT first; train-only global standardization. Source chronology: train_end=int(int(N*.8)*.875), val_end=int(N*.8); final20% test never evaluated in this pilot. History151 observations; forecast75 steps; slow-window75. Use chronological training origins with all targets inside training. Validation roots every75 samples beginning at train_end-1, so future targets do not overlap. Historical observations from earlier validation times are allowed at later rolling origins. No test metric or test-based hyperparameter choice.

Alignment: model input at indexi is y_i; source predicts next observation at that index. Feed deterministic calendar features for time_(i+1) as the action/covariate input: sine/cosine of hour, weekday and day-of-year (annual period365.2425). For each window use225 source input positions,151 valid history observations then74 finite placeholders with false masks. Score source outputs150:225, corresponding exactly to75 future labels. All required calendar conditions end at the last scored future target; there is no unused extra future control. Verify forecast invariance to future observation placeholders. No target is fed as an observed future input. Future-label losses cannot be constructed from source same-time outputs.

Pre-fit correction: the initial150-history proposal failed its unused-control invariance preflight. Source inspection confirmed the abstract action encoder reads the whole next75-position window, so the last control is not padding. Changing history to151 keeps total source length225, uses exactly75 future controls/targets, and needs no native model patch. The failed preflight and script snapshot are retained. This is an adapter alignment correction before fitting or validation metrics, not a model failure or tuned method.

Training: native Gaussian mean/variance head, diagonal Gaussian NLL including constant; Adam lr.003, batch16, gradient norm clip5. Maximum1500 updates, validation every100 updates; stop after8 non-improving checks, best validation NLL checkpoint. All settings fixed before fitting. Do not interpret a single pilot as stable performance or a completed original reproduction. Numerical failures trigger implementation/protocol diagnosis, with each attempt preserved; no test-driven tuning. Save initialized/last/best state, optimizer and RNG states, exact config, all raw stdout/stderr, training and validation JSONL, model/source/data hashes, timings and memory.

Strong ordinary references: observed-context persistence,24-step seasonal repeat; fixed Ridge ARX using training-only coefficients and residual variance, target lags1..24 plus48/72/96/120/144 and deterministic next-time calendar conditions. No validation calibration of these references. They diagnose gross underfitting; they do not establish equal capacity or compute. A poor learned result must not automatically be blamed on the cycle15 approximation.

Learned relevance diagnostics after training: (1) inspect A,C, context variance and process-noise contributions; (2) native forecast output mean/variance under future-placeholder perturbation; (3) during one entirely unobserved slow window, compare native projected covariance, ordinary full fast-state covariance without cross-scale dependence, and full fast/context augmented covariance from the same factorized initial belief. Keep native mean fixed and pass projected covariance summaries through the unchanged native variance decoder. This is an inference diagnostic, not a new trained method or proof of the true posterior. Initial cross-covariance is unknown and set to0 in both controls. Separating spatial and cross-scale terms is required. Post-hoc changes may be out of the variance decoder's training distribution; do not equate improvement/deterioration with a definitive method result.

Falsification: negligible learned context contribution or negligible decoded sensitivity weakens the practical relevance of the cell witness. Standard adequate corrections at matched cost weaken a new-architecture claim. Any future method requires independent held-out data, sufficient training, competing explanations, existing Bayesian/particle/recognition models and multiple seeds. No architecture innovation or final direction is accepted from this pilot alone.
