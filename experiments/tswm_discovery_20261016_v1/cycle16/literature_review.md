# Literature boundaries — cycle16

Research target: a general time-series world-model framework. One series is a diagnostic environment, not the contribution. Earlier sealed reviews remain authoritative for their original evidence; this is an incremental review.

- [RAMP,2607.18883v1](https://arxiv.org/html/2607.18883v1): learns recognition-parametrized, coupled node beliefs by amortized message transformations on latent trees. Theorem3 concerns sufficient statistics at the population/global optimum under its assumptions. Its Gaussian experiment compares marginal beliefs against exact and mean-field inference; interactions are implicit in message factors. Discussion explicitly reserves loopy graphs for future work. This does not make ordinary state augmentation or a tree-to-loopy extension novel. The primary HTML contains no GitHub link; code availability is unverified, and no RAMP execution is claimed.
- [Variational meta-learning inference for low dimensional neural system identification,2607.18965v1](https://arxiv.org/html/2607.18965v1): a hypernetwork maps a small task latent to neural-system parameters. A variational encoder initializes test-time MAP refinement followed by a Hessian-based Laplace posterior. Its own Remark3 discusses multimodal ambiguity under short/narrowband Bouc–Wen excitation and suggests multiple Laplace modes. Therefore a generic task latent, Bayesian adaptation, or replacing a single mode with a mixture is not an innovation. Official [code](https://github.com/mattrufolo/VAE-sysid-neural-manifold) is available; nine selected source/notebook/license files109087bytes are pinned at89a35d3e3e95e4ad8cc82dc74e579c30a41181db. No model execution or reproduction is claimed.
- [Martingale Posterior Neural Processes,2304.09431v1](https://arxiv.org/html/2304.09431v1): models functional uncertainty through exchangeable predictive pseudo-data, rather than only a Gaussian task latent. Its task setup assumes input/output pairs conditionally independent given a function. It also evaluates simulated Lotka–Volterra and real hare–lynx regression, reporting model-mismatch limitations. Temporal data dependence alone does not establish a new contribution: dynamical likelihoods and Bayesian system identification already address it. No execution is claimed.
