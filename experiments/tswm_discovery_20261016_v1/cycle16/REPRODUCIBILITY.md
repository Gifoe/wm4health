# Reproduction and evidence contract

The completed scientific experiment is a source-native MTS3 framework transfer to NP. It is not a reproduction of original MTS3 data/numbers, a comparison against the original WorldTS information protocol, or an accepted new method. The decision to stop the covariance-repair line is recorded in final_research_direction.md. The overall autonomous research project is still incomplete.

Source: official MTS3 ab971c0ec43df7664c4b727ca69d5b8dd0cab5da, archived in the sibling cycle15/upstream/MTS3. All152 materialized files are checked against the cycle15 source manifest. No native source file was modified. config_tools.py supplies a safe YAML dictionary/attribute facade because OmegaConf is absent. It preserves original YAML values. Runtime profile and all adapter/plan/source/data/checkpoint hashes are retained.

Environment used: Windows server, one RTX5090, Python3.10.20, torch2.8.0+cu128, NumPy1.26.4; main project .venv. TF32 is disabled for both fitting and diagnostics. Thread/affinity/environment settings are in scripts/runtime_profile.py. The peak Torch allocator value is not total driver/library GPU memory.

Prepared numerical data: outputs/data/NP_trainval.npz and registry.json contain all actual training/validation inputs, targets, origins and train-only scaling constants. The final20% test segment is not exported in this file. The original NP CSV hash and path are recorded for provenance; data preparation needs that cached CSV, while saved-array/model verification does not require downloading test targets. Future conditions are deterministic calendar values only. The two raw future forecast columns are excluded. The first150-history proposal was corrected to151 before fitting after an alignment preflight failed; native abstract action inference reads the entire next slow-window plan.

Training: scripts/train_full_pilot.py; full capture via capture_train1.py/job_runner.py.1500 updates,16 validation checks including initialization; best validation NLL at1100. Every saved checkpoint includes model, optimizer, CPU/CUDA RNG and NumPy generator state. The initial failed background-launch folder is a launch-aborted attempt without a live training worker or scientific result. The successful WMI-launched job is outputs/jobs/native_mts3_NP_seed2021_attempt1 and terminated with exit0. Complete stdout/stderr and per-update JSONL are retained.

Final gate: scripts/diagnose_learned_covariance.py, captured by capture_diagnostic.py. Its source hash is the same as the earlier fixedstep100 smoke. It checks the completed fit, selects the recorded best checkpoint, verifies source/data, and captures unchanged native means/covariance factors. Both dense controls start with the same assumed zero cross-covariance; they are descriptive post-hoc controls, not posterior truth. All69 validation origins are evaluated. No new model is fit for the controls.

Independent numerical verification: scripts/verify_covariance_arrays.py checks the saved diagnostic against closed-form matrix powers and sums in NumPy, and recomputes every reported metric. The original successful invocation targeted outputs/diagnostics/final_step001100; its receipt is preserved there. The verifier deliberately refuses to replace an existing receipt. To repeat, copy only results.json and arrays.npz into a fresh verification directory, then invoke the verifier on that directory.

Complete-pilot integrity: scripts/audit_completed_pilot.py, captured by capture_completed_audit.py, verifies all1500 training records,16 validation snapshots/checkpoints, split boundaries, source/config/plan hashes, best-checkpoint selection and exact native output replay. It does not establish optimal convergence or generality. scripts/summarize_full_gate.py produces the machine-readable analysis and figures after independent verification. These writers preserve existing outputs by assertions; full training/re-analysis requires a fresh experiment copy, with the pinned sibling source and prepared data paths retained. Do not overwrite the archived run.
