# C80 ordinary identification and numerical-truth controls

Frozen AFTER inspecting the six native tutorial scores, including pendulum new-IC NRMSE1.6212. This is a post-discovery falsification control, not independently held-out confirmation or a new method. It cannot establish a novel architectural limitation. Keep native source/weights/predictions unchanged; no neural training, no hyperparameter choice from the two clean evaluation trajectories.

Use only the exact same one noisy256-point source trajectory and times supplied to FIM. Fit ordinary weak-integral polynomial vector-field regression. Two fixed, common sparse-identification libraries are retained: all2D monomials total degree<=3 (including1), and those monomials plus sin/cos of both raw state coordinates. The latter is source-informed after reading the benchmark equations, not an equation-blind universal comparator; all coefficients remain unknown and fitted from the noisy context. Do not add rational functions or change a library after seeing these control scores.

For each system fit on the first192 available context observations, with coordinate mean/SD from those192 only. Build weak equations using trapezoidal integrated features over all windows of8,16,32 intervals and observed endpoint state increments. Standardize integrated feature columns by RMS. Ridge candidates1e-6,1e-3,1; sequential coefficient thresholds0 or0.03 applied for5 fixed iterations; two libraries gives12 candidates per system. Select minimum unnormalized observed-context MSE on its remaining65 points (starting at index191); no clean trajectory, true field, second IC, source constants or test metric enters selection. Invalid solves are retained as failures, not silently dropped/replaced. Refitting the selected candidate on all256 context points is the sole final fit per system. This is inference-time ordinary per-system fitting, not matched pretraining cost with FIM.

Use the same RK45 rtol1e-4/atol1e-6 as native tutorial for both ICs. Preserve unsuccessful cases; fixed engineering guards of20,000 RHS calls or absolute state1e6 terminate a case and are reported as failures. No state/output clipping. There is no true-dynamics parameter supplied to an ordinary fit. Record every candidate, chosen config, final coefficients, singular values/condition information, integration status and full arrays on server G.

Separately integrate the actual public benchmark equations/constants from both clean initial states using the same solver tolerances. This is a PRIVILEGED numerical/reference diagnostic, not a learned baseline or operational method. It checks that reference equations, initial-state identities and numerical integration are consistent. A low known-equation error does not prove data-only identifiability.

Interpretation: if a standard same-context fit substantially repairs the measured new-IC deficit, do not invent a new architecture for it. If not, coverage/identifiability, noise and library mismatch remain competing explanations; one pendulum example cannot establish a general world-model gap. Current literature already studies context-compatible off-support field ambiguity, GP/ensemble uncertainty and active identification. The broad research objective remains ACTIVE/UNACHIEVED.
