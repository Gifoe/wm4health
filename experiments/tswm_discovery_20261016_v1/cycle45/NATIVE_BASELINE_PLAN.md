# Native NCDSSM qualification plan

Freeze before any native numerical result in C45. Qualification weights are discarded and never used as comparative effects. Do not run while C44 dedicated latency measurements are active. Keep the original source immutable and version any compatibility repair in a separate runtime copy with an exact manifest. Do not stub numerical operations or silently replace the author model with a custom SSM.

First inspect existing dependency metadata and the private RK4 symbol's source signature without importing numerical libraries or changing global packages. Import the pinned native core through a project-local path. If a required small dependency is missing, use an audited official project-local wheel/source, with versions and hashes; preserve import failures and explain adaptations.

The numerical qualification has three distinct purposes:

- **Linear inference arithmetic.** Native BaseLTI with an explicitly declared stable two-dimensional F, diagonal Q/R/prior covariance and fixed H. Irregular observed times including one wholly missing step. Use the native matrix-exponential predictor where supported; independently derive discrete transition/noise from SciPy expm and the stationary Lyapunov solution, then NumPy Kalman updates/likelihood. Compare means/covariances/log density and one finite-difference parameter gradient in float64. This known-parameter fixture is only a numerical control, not information supplied to a learner or a model-quality comparison.
- **Sampling contract.** On the same fixed linear system and observed history, compare native future-time means/covariances and cross-time covariance with the exact joint Gaussian. Use sufficiently many independent draws and predeclared MC tolerances. Also draw ordinary Markov paths with the same filtered posterior and fitted process parameters; retain both outputs. Check a temporal-difference variance as an observable path property. No claim of a new method follows from a standard sampling correction. Trace the outer auxiliary draw count/batch shape separately, without confusing shared outer randomness with the within-path temporal law.
- **Actual nonlinear core.** Use the original NCDSSMNL/AuxInferenceModel/GaussianOutput/MLP and an explicit small configuration modeled on the provided pendulum setup. Run forward/backward, a small fixed number of discarded updates, finite forecast/masked-input checks and deterministic checkpoint replay. No claim of convergence or original-paper headline reproduction. Test only distinct changed critical paths; do not expand qualification into a benchmark substitute.

All fixtures, dtype/solver settings, source hashes, seeds, failures, outputs and selected-source paths must be retained. Do not infer that an original forecasting paper promised iid joint path samples solely from an array shape. The result is a reliable complete baseline contract for subsequent framework experiments.

Execution constants before any numerical run: linear state dimension2, F=[[-.3,.2],[-.1,-.4]], diagonal process variance rates[.07,.04], observation variance[.05,.08], prior mean[.15,-.12]/variance[.3,.4], H=[[1,.3],[.2,1]]. Past times[0,.2,.7], future[1.2,1.8,2.7]. Float64 linear mean/covariance/log-likelihood tolerance1e-8, finite-difference gradient tolerance5e-6 with step1e-5.16384 native and independent Markov draws, five-Gaussian-SE sampling tolerances plus1e-5 roundoff floor; retain native discrepancy rather than require a false joint-law match. Nonlinear qualification: author components, z6/aux2/y2/MLP64×1/Softplus, RK4 step.05,10 discarded Adam1e-3 updates/clip10 on a fixed small oscillatory fixture, CPUfloat32. Capture auxiliary draw counts and history batch sizes. These are API/numerical checks, not a trained benchmark or a new effect.

The actual new framework question and training protocol remain undecided. Ordinary NCDSSM/modular combinations are eligible strong contenders, not deliberately weakened baselines. A generic SSM's expressivity alone is not a veto on a useful new learning recipe; direct equivalence and real evidence are required.
