# C65: native conditional diffusion as a reusable intervention simulator

Pre-execution design. Overall goal remains a reusable time-series world-model research gap, not optimization of these simulator scores. This cycle can reject a candidate; it does not assume novelty. C64's causal AR and frozen-joint factorization already solved its Gaussian attribution problem. Causal sequence generation, arbitrary-mask imputation, diffusion forcing and posterior SMC are existing methods. A failure of an intentionally restricted conditional-only API is not sufficient evidence.

Use actual CSDI source at commit 7f24a436f08d98853a6b43d4f7f04e5a65ecdf27, retaining its complete native model, diffusion loss, side embeddings and imputation sampler. This is a cross-mechanism transfer of an existing architecture, not reproduction of original CSDI benchmark scores. No pretrained weight reuse is claimed. Original files and MIT license are preserved. No new denoising network is proposed.

Two independently trained mechanisms, three independent training/data seeds2021/2022/2023 each. Both begin Y0=.25, H8, behavior U_t=-.75Y_(t-1)+.5eta_t, independent innovations. Linear: Y_t=.8Y_(t-1)+.7U_t+.5epsilon_t. Nonlinear: Y_t=.65Y_(t-1)+.4tanh(2Y_(t-1))+.6U_t+.35epsilon_t. All states observed, no hidden confounding. 16384 training, 4096 validation, 8192 reserved observational-test trajectories per cell. Test arrays must not select fitting settings. These are two synthetic mechanisms, not cross-domain or zero-shot evidence.

For each corpus train two native CSDI configurations: (a) native random masks; (b) an existing conditional-mask coverage control with .5 probability native random mask, .25 whole-plan block mask and .25 temporal-prefix mask. This control prevents attributing ordinary mask-distribution shift to a new world-model gap. Both share channels32, layers2, embedding32, heads4, time embedding16, feature embedding8, official 50-step quadratic schedule .0001 to .5, Adam lr.001, batch64. Save checkpoints at2000/8000 updates. Select between these two using the same fixed validation denoising loss, separately exposing block/prefix components; no intervention truth or observational test selection. No further test-based tuning. Report exact target-scalar exposures and runtimes; step count alone does not make compute equivalent.

Also train a conventional causal Gaussian-mixture transition MLP, 2 inputs, two width224 hidden layers, 3 mixture components, Adam lr.001, batch512 transitions, checkpoints2000/8000 chosen by validation one-step NLL. Same training trajectories; parameter/compute counts reported. Existing causal modeling is a strong baseline, not a proposed contribution. A linear-Gaussian AR fit and true simulator provide additional attribution where applicable.

Before training qualify native CPU/GPU forward and gradients, finite loss/weights, source hashes and sampler masking contract. Use GPU only if finite qualification passes; do not change drivers, other environments or unrelated processes. Periodically seal checkpoints and process receipts. Every stochastic cell is independently traceable.

After fitting, freeze both CSDI checkpoints. Compare whole-plan conditioning (all queried U, no Y) with sequential prefix queries to the SAME checkpoint: at step t reveal only Y_<t and U_<=t, sample missing variables natively, keep only current Y_t, and repeat. The second operation is classical sequential g-computation using arbitrary-mask queries, not a new algorithm. Future actions are hidden until their step. The coverage-trained model tests whether a known task-distribution repair suffices.

Fixed interventions zero and .4sin(2pi(t+1)/8). Evaluate512 generated trajectories per law with three fixed MC seeds, at native50 denoising steps. Report cost (including H repeated sampler calls), law metrics and finite-population references. No CFG amplification or test-guided sampler search. Exact simulator do samples are privileged references. Exact observational conditional samples can be obtained by rejection from do trajectories with acceptance exp(-.5 sum_{t>=2}((u_t+.75Y_(t-1))/.5)^2); the first action term is constant and cancels. The envelope is one. Cap proposals explicitly and report failure if insufficient acceptance, never silently substitute approximate truth.

Distributional evaluation should use fixed projected empirical distances, marginal/tail diagnostics and iid target references, not Gaussian-only law claims. Gate interpretation on observational conditional fidelity and validation training quality. If these fail, label undertraining/mask mismatch/model approximation rather than a causal research gap. No final direction accepted unless a new failure survives strongest applicable existing controls, multiple independent mechanisms/seeds and a separate real-data or held-out-mechanism test. C65 alone cannot satisfy that final requirement.

Related boundary: CSDI already supplies conditional masks; Diffusion Forcing and Vid2World already causalize sequence generators. CaTSG and ADMIT overlap causal trajectory generation. New architecture/method design is deferred until this ordinary-control test warrants it.
