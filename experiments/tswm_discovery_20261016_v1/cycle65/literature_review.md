# C65 literature and novelty boundary

This cycle tests reuse of an actual conditional generator across observational and intervention queries. It does not propose a new architecture or claim that causal generation, sequential g-computation, masking or reverse-variance correction is new. The aim remains a reusable time-series world-model research problem, with scientific evidence beyond fitting a particular dataset. C65's two simulated mechanisms are attribution tests, not the final scope.

| Primary source | Boundary relevant to this experiment | Evidence actually inspected |
|---|---|---|
| [CSDI](https://arxiv.org/abs/2107.03502), [pinned source](https://github.com/ermongroup/CSDI/tree/7f24a436f08d98853a6b43d4f7f04e5a65ecdf27) | Conditional-mask time-series diffusion is an existing reusable API. Sequentially querying it under prefixes is a classical causal-factorization operation. | Original main_model.py and diff_models.py executed unchanged. Smaller declared native configuration and new data/caller are a transfer experiment; original benchmark reproduction is not claimed. MIT license preserved. |
| [Conditional Generative Models are Sufficient to Sample from Any Causal Effect Estimand, NeurIPS2024](https://proceedings.neurips.cc/paper_files/paper/2024/hash/8d6233829f97fe8eb3fa7d2ab774aedc-Abstract-Conference.html) | Conditional-generative push-forward constructions already address identifiable causal estimands. A generic proposal to compose diffusion conditionals into causal sampling would duplicate known work. | Primary abstract-level scope checked; no implementation executed here. It does not certify that the specific finite CSDI conditional approximations are accurate. |
| [OrthoGen, 7 October2026](https://arxiv.org/html/2610.10210), [pinned author code](https://github.com/tgarriga/OrthoGen/tree/77b93f16d6ee3669b27aaaeb69cc89d9658f66f5) | Generative recursive g-computation and doubly robust orthogonal learners for conditional outcome distributions over time already exist. They cover more than naive propensity weighting. | README, learners.py, nuisances.py and synthetic flow configuration inspected. The pinned code uses binary propensity models and checks a fitted regime. It targets a regime-specific outcome distribution; do not equate that interface with arbitrary adaptive path simulation. No empirical defeat is claimed; no root license located, source not mirrored. |
| [Vid2World, ICLR2026](https://arxiv.org/html/2505.14357v3) and [author project](https://knightnemo.github.io/vid2world/) | Repurposing noncausal sequence diffusion into interactive generation via causalization and action guidance has direct adjacent prior art. Merely porting it to numerical time series is not a sufficient innovation claim. | Primary paper and project inspected; video backbone not executed. Temporal nonanticipativity and interventional identification remain distinct assumptions. |
| [CaTSG](https://arxiv.org/html/2509.20846), [pinned code](https://github.com/microsoft/TimeCraft/tree/ad38a7df05fa47f3142db60f2c92d7e6a7f04cc0/CaTSG) | Static latent-environment/backdoor-adjusted conditional generation overlaps a generic causal-generation framework. It does not automatically prove treatment-feedback handling. | Native configuration, dataset, whole-context UNet and environment-guidance code inspected. No CaTSG training or original-task failure is asserted. |
| [ADMIT](https://arxiv.org/html/2609.34433) | Sequential g-computation, multimodal representation and explicit constraints already form a proposed intervention-simulation framework. This narrows novelty beyond merely combining those terms. | Primary method/limitations inspected; no author code execution. Numerical prospective assumptions and representation leakage need their own verification. |
| [Improved DDPM, ICML2021](https://proceedings.mlr.press/v139/nichol21a.html) | Reverse-process variance and sampling efficiency are established research subjects. A fixed-variance denoiser's finite-step variance loss is not itself a new time-series world-model mechanism. | Primary abstract verified. C65 separately quantifies the native sampler with a privileged exact linear denoiser, keeping the trained-model runs unchanged. |

C64 remains negative evidence against the broad frozen-forecaster causalization narrative: ordinary causal AR and same-joint temporal factorization are already strong. C65 adds actual learned diffusion, explicit query-mask coverage, near-matched parameter counts, independent training seeds, nonlinear dynamics, exact conditional references, validation Bayes-risk and native sampler references. If existing causal density or ordinary mask coverage explains the results, the correct response is to reject the candidate rather than invent a new name.

Full-path simulation, terminal potential-outcome distributions, observational conditionals and shared-noise individual counterfactuals are different tasks. The current protocol tests the first three relevant law views only; no individual-noise counterfactual or clinical policy conclusion is supported. No final research direction has been accepted.
