# Fixed evaluation specification before the trained models are scored

Each native CSDI checkpoint produces both a whole-plan conditional law and a sequential-prefix g-computation law. The latter hides future actions until their step and reuses the identical frozen model. Two training mask regimes distinguish conditional-query coverage from causal semantics. Every law uses512 trajectories and MC seeds2021/2022/2023; all are retained. Select the checkpoint by validation DSM only. Compare same-data causal MDN and causal AR. Initial state is known and fixed, no unobserved state or confounding.

For each mechanism and the two fixed plans, generate8192 independent true do trajectories and8192 exact observational-conditional trajectories. The latter uses rejection from the do law; discard only by a valid likelihood-ratio envelope, not manual inspection. Bound proposals at2^25 per query; if insufficient, mark oracle incomplete and do not score against fabricated truth. The first action likelihood is constant, so only remaining policy factors enter acceptance. At linear mechanism, check sample mean/covariance against analytic Gaussian laws using a fixed6-standard-error simultaneous diagnostic; this is a sanity check, not a learned performance gate.

Primary law comparison: exact one-dimensional empirical W1 after projection onto128 fixed normalized Gaussian directions (RNG650999) plus8 coordinate axes. Average these136 projected distances and normalize by the target reference's average projected standard deviation. This is a finite sliced distance, not full multivariate W1/W2. Also report terminal marginal W1, path mean MSE, variance-trace ratio, and terminal probability of |Y8|>2. Score each generated law against both observational and interventional references with explicit target names. Treat the dual scores as two views of one generated law, not independent runs.

For a sampling floor, generate independent exact do and observational-conditional references of the SAME512-trajectory budget for each query and each of three MC seeds. Scores compare these to the8192 reference; never infer a research gap merely from a nonzero empirical distance. No pass threshold is introduced from the observed test results. The results should be interpreted relative to iid variability and validation/conditional-law fidelity, with three training seeds and only two known systems.

Save every sample array, oracle reference, native checkpoint, hash and runtime on the authorized server storage. Count native denoiser calls (50 block versus400 prefix per particle batch) and wall time with CUDA synchronization. MDN/AR calls, training target exposures and parameter counts remain explicit. No claim of equal compute from equal optimizer steps. No test-based tuning, CFG amplification, additional architecture search or future information use.
