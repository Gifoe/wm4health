# Post-pilot classical sensitivity control

Exploratory, specified after cycle20 test inspection and before calculating this control. No new test-tuned model design. Existing active-subspace/derivative-informed dimension reduction is prior art (Constantine,Dow,Wang,SIAM2014,doi10.1137/130916138). It must not be renamed as a new neural method.

Reuse each of the nine completed raw-observation teachers and unchanged splits. Compare two output choices: all teacher outputs; or the action-responsive teacher output span estimated from in-support four-action prediction differences on8192 TRAIN states (95% response-energy rank). The second shares cycle21's proposed target-selection ingredient; it is not an independent prior method that already supplies automatic target selection. Comparing it to the all-output control isolates target selection versus the choice of compressor.

For512 TRAIN states crossed with four actions, form the mean input-gradient outer product of the selected teacher outputs. Keep exactly four input eigenvectors, whiten those coordinates on TRAIN, and freeze this encoder. Fit a polynomial ridge transition from(z,current action) to the next frozen z. Degree1/2/3 and relative ridge1e-6/1e-3/.1 selected using only validation latent MSE, then retain the fitted model. No physical labels fit the projection or transition. A linear physical/gain diagnostic readout is fitted after encoder freezing. Evaluate the original pilot test once per fixed specification; this remains a post-pilot old-cohort diagnostic, not independent confirmation.

Save teacher/data/model hashes, output/input spectra, projections, whitening, coefficients,all validation scores,test predictions and metrics. Check teacher input gradients by independent finite differences on four TRAIN states(h1e-3,absolute tolerance.002 forfloat32). If ordinary sensitivity compression recovers the compact state, do not claim a sophisticated new encoder architecture is needed. If only the action-selected output variant works, keep the distinction between an established compressor and the still-unverified output-selection contribution. Either result needs independent/native realistic evidence before recommendation.
