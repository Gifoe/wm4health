# Source-grounded candidate boundary, before test metrics

General target: an observation-grounded time-series world-model framework. This pilot asks whether a particular representation objective loses a measured variable that changes physical dynamics. It does not propose a new world model yet.

| Primary source | Supported fact | Candidate distinction / required control |
|---|---|---|
| [Predictive Objectives Discard Exogenous Control-Relevant Features,2606.30068v1](https://arxiv.org/html/2606.30068v1) | A fresh exogenous feature determines reward; reconstruction/reward grounding retain it while tested predictive variants omit it. Small synthetic controlled study. | Incoming-innovation pilot removes rewards and makes the observed feature a parent of the next physical state. This is a narrower question, not permission to claim exogenous relevance itself as new. |
| [Sensorimotor World Models,2606.20104v1](https://arxiv.org/html/2606.20104v1) | Joint latent forward+inverse MSE, no EMA or separate latent regularizer. Random distractors in reported tests are not needed to predict the controlled physical update. | Our joint+inverse+VICReg arm is a controlled mathematical variant, not native SMWM. A failure here is not a reproduction failure or a refutation of its stated empirical scope. Standalone inverse-only training remains a source-compatible follow-up if the candidate survives. |
| [Hamiltonian JEPA,2609.33497v1](https://arxiv.org/html/2609.33497v1) | Separate perceptual/control spaces, inherited covariance, structured dynamics and tied port-inverse prediction weighting. | Existing stronger control geometry must be considered; generic state/control separation and anti-collapse are not new. Its full model is not executed by this MLP pilot. |
| [SLIM,2610.03137v1](https://arxiv.org/html/2610.03137v1) | Small action-responsive image regions motivate inverse-action auxiliary training and planning diagnostics. | Capacity/distractor sensitivity is already measured. Current question concerns a known current driver with unpredictable next value, not simply small moving objects. |
| [MoP-JEPA,2607.05238v1](https://arxiv.org/html/2607.05238v1) | Uses EMA stop-gradient, unit-normalized latent targets/heads, hard assignments and a context-only router. | The pilot's unnormalized joint-target2-head minimum-MSE control omits EMA/router and is NOT native MoP-JEPA. It only tests whether a simple mixture alone changes the failure. Before claiming stochastic methods insufficient, use source-compatible EMA/normalized/router or another competent stochastic state-space control. |
| [CausalDreamer,2610.12016v1](https://arxiv.org/html/2610.12016v1) | Frozen-tokenizer re-encoding into four controllability/reward groups with residual reconstruction and reward prediction. | Reward-conditioned feature selection and factorized world representations are covered. A reward-free physical-driver claim needs separate evidence. |
| [Action-sufficient representations,ICML2022](https://proceedings.mlr.press/v162/huang22f.html) | Structured environment modeling and compact sufficient states for reward-directed control. | Sufficient-state learning is established; new novelty must concern a precise modern objective/setting and a surviving practical mechanism. |
| [AC-State,2207.08229](https://arxiv.org/abs/2207.08229) | Multi-step inverse state discovery under stated exogenous-block assumptions; ACDF/PcLast extend related state/reachability questions. | Do not replace reward relevance with controllability or assume independent distractor guarantees apply to a variable that modulates controlled dynamics. Existing multi-step state-discovery methods are appropriate controls for the deferred delayed-observability branch. |

Six version-pinned primary HTML sources and extracted reading files are archived under outputs/literature. Source bytes and read claims are distinguished from executions: no native implementation of these six papers has been reproduced in cycle20. Var-JEPA2603.20111, JEDI2605.13013, MA-JEPA2609.33563 and the earlier UWM/MDNVJEPA work remain stochastic competitors; this pilot cannot prove they fail.

Optimizer inference, not source claim: an incoming observed innovation may be useful on the conditioning side while costly as a self-predicted target. This distinction is testable against EMA, likelihood, mixture and observation prediction. If an ordinary existing control removes it without losing the representation budget, a new architecture is not justified at this scope. The candidate's strongest rescue is a more precise representation/target-alignment question with proper stochastic controls; its weakest link is current reliance on small fully observed systems rather than independent realistic time series.
