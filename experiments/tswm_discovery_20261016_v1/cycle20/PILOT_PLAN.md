# Causal incoming innovations in learned world states: exploratory pilot

Scope: a candidate mechanism question for a GENERAL time-series world model, not a new architecture or a dataset optimization. Novelty remains uncertain. The previous cycle19 event audit is sealed and will not be modified.

Source-backed starting point:2606.30068v1 isolates unpredictable exogenous bits that determine reward, not physical transition laws. AC-State/ACDF and action-sufficient representations already study state discovery, while Sensorimotor/SLIM and Hamiltonian JEPA use action/inverse objectives. Reconstruction-free stochastic alternatives (MoP-JEPA, variational JEPA, JEDI/MA-JEPA) are relevant competitors. Do not claim generic uncontrollable-but-relevant features, inverse insufficiency, stochastic latent dynamics or observation prediction as new.

Three branches: A(refine/invert2606.30068): incoming observed innovations are unpredictable as future targets but causally modulate physical transitions; test whether self-targeted representation learning omits them. B(refine older PSR/action-state work): information needed only by longer action sequences; defer until A's ordinary controls are resolved. C(transfer stochastic state-space modeling): posterior assimilation versus prior rollout; use as an existing control, not a novelty claim. This pilot selects A for evidence, with reconstruction/ordinary prediction and probabilistic latent controls as concrete rescue/falsification routes.

Three fully observed Markov families with learned observation encoders: stable coupled linear states, damped rotating states, and saturating dissipative states. Physical state(q,p) evolves under two random binary actions. A visible fresh gain g_t in{0.4,1.6}, independent each sample, modulates one action's physical effect. Future g is unknown. Nine action-independent AR(.98) nuisance coordinates compete for representation space. A fixed invertible orthogonal mix hides channel identities. Observation normalization is fitted on training only. The gain is causally relevant to next physical observations, not merely a reward bit. No rewards or physical labels enter world-model fitting. Random actions cover all four combinations in every split; gain support is identical in train/test. Counterfactual gain flips are evaluated within that support. This is a controlled task transfer, not a native image-benchmark reproduction or proof of real-world prevalence.

Dataset seeds20262011/12/13 with family offsets:192/64/128 independent trajectories,64 recorded transitions each, after64 burn-in steps. State/gain/nuisance/action streams generated explicitly, no windows shared between splits. Development numerical tests use a separate seed. Only the train split determines normalization. Split files/source hashes are retained.

Fixed models: two-hidden-layer64-wide SiLU observation encoder to4 dimensions; two-layer64 predictor. Losses: joint-target latent MSE; joint+inverse-action MSE; EMA-target+inverse; diagonal Gaussian latent NLL+inverse; two-component hard-min latent MSE+inverse; observation-space future prediction through the same4D encoder+inverse; ordinary raw-observation MLP. Latent models share variance/covariance anti-collapse penalties(var weight10,cov weight1); inverse weight1. Mixture/likelihood variants are mathematical task controls, NOT native MoP/Var-JEPA implementations. Additional full-capacity12D joint+inverse control. No known physical equations or generator parameters are passed to models. All three families, seeds2021/22/23, all eight specifications =>72 fits. Adam lr1e-3,batch256,1500 updates,last weights; gradient norm clipping10. EMA decay.99. No physical validation/test score selects world-model weights or loss weights. Data/step budget matched across learned bottleneck arms; full-observation baseline is labeled as using larger state access.

Posthoc diagnostics use frozen encoders. Linear ridge and a two-layer64 MLP are fit on training physical labels to decode current(q,p,g), and to predict next(q,p) from(encoded current state,action). These are privileged DIAGNOSTIC probes, not method-training objectives. Decoder MLP500 updates,lr2e-3,batch256; select linear/MLP by validation MSE for each diagnostic. Physical labels never update world encoders. This distinguishes actual information loss from a weak linear probe or an underfit latent transition. Record current-state decoding, gain classification/R2, oracle successor decoding, native successor prediction, and within-support gain-modulation response error. Mixture physical means average decoded components, not decoded mean latent. Keep all candidate probe scores.

Train all world/probe models before accessing test split metrics. Test results cannot change model dimensions, steps, weights or family definitions. Report training/validation learning curves and population-style descriptive summaries across three initializations, without treating seeds as independent physical tasks. Save checkpoints, data, raw test predictions, RNG/config/script/plan/environment hashes and terminal job logs.

Numerical invariants: observation transform inverse exact; gain flip alters exactly the declared physical update; future gain is not supplied; split trajectory IDs disjoint; class supports equal; all finite. Full-observation forecasting validation readiness requires normalized physical MSE<.05 on each family; otherwise label the pilot undertrained and make no representation-failure claim. A successful EMA, probabilistic, observation-prediction or full-capacity existing control falsifies any claim that a new architecture is necessary at this scope. If only task-specific probes look positive, no new general framework has been established. A surviving candidate still needs actual compatible source-native controls and an independent realistic time-series benchmark before recommendation.
