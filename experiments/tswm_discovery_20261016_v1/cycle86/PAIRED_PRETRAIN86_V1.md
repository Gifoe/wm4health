# C86 paired factual-learning control

This extension is frozen after the sampler diagnostic and before generating a new evaluation population. It tests an elementary learning consequence, not a new architecture and not an official FIM reproduction. A downstream effect is not assumed from a sampler histogram alone.

Use the three saved mechanism pools. Each arm receives1024 distinct TRAIN mechanisms and the same number of short factual windows. Arm A: mechanisms and original first initial conditions surviving the native whole-trajectory threshold3 with one path. Arm B: exactly the same mechanism IDs as A, independently resampled initial conditions, breaking the selection-created initial-condition association while preserving the selected mechanism population. Arm C:1024 uniformly drawn TRAIN mechanisms with their original first initial conditions, preserving numerically finite short prefixes from the unselected pool. All short windows are finite and generated by exact linear flow. This does not claim to solve recovery from genuinely nonfinite labels.

Each window has8 observed states followed by16 target states at dt0.05; add iid measurement noise0.01 to all24 states after selection. No A/rate/rotation labels enter model training. Source validation uses up to384 distinct held-out mechanism IDs from the corresponding arm's population and initial-condition rule. Reuse the same noise for overlapping A/C IDs. Each arm's B-style resampled initial state and noise is fixed independently before training. Mechanism IDs are disjoint across TRAIN/VAL/test partitions.

Train two small existing architectures: (1) a64x64 MLP history encoder predicting three entries of a bounded symmetric continuous-time linear generator, with ordinary RK4 free rollout; (2) a64x64 direct MLP predicting16 future states. These are controlled meta-predictors, not universal foundation models. In each seed/architecture pair, initialize all arms identically and use the same minibatch-index stream. Adam3e-4, batch64,3000 updates; evaluate source VAL every300 steps and select minimum noisy-future MSE, including step0. Preserve all checkpoints and schedules. No per-arm hyperparameter tuning. Source qualification requires selected VAL MSE to be below persistence on that same population; failures are retained and block a generalization claim for that fit.

Seal all18 fits and their selected states before generating seed2026864 with1024 new mechanisms and independent initial states/noise. Evaluate every selected fit on the identical unselected population, on its threshold3-selected subset, and on the complement. Primary horizon16; report normalized RMS error using each true trajectory RMS with floor0.1 and its raw MSE, failure count and per-mechanism errors. No neural H64 comparison is predeclared because the direct predictor's native horizon is16.

Strong ordinary controls are persistence and per-context two-dimensional ridge linear identification. The latter fits T-I from seven noisy observed transitions, with ridge0/1e-4/0.01/0.1/1 chosen only on each training seed's unselected source VAL IDs; it then free-simulates16 steps. It has no hidden parameter/state labels. Also retain the family-specific generator architecture's structural advantage explicitly. If an ordinary method suffices, do not claim a new predictor is required.

This study changes the training cohort while matching retained short-window counts, initialization, architecture, update counts and noisy-label budgets. It does not match simulator-attempt counts or the distribution of mechanisms; changing that distribution is the intervention. Arm B isolates resampled initial conditions only within A's selected mechanism cohort. Arm C differs in mechanism prior as well as its joint initial-state distribution. A positive C-A result would support a sampler-induced learning effect in this family, not validate a novel general time-series world-model method or causal explanation of any released checkpoint.
