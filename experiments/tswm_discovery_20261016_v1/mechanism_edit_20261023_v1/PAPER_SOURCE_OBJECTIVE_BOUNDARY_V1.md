# Paper versus current released objective

The [DALI v3 paper, Eq.2 and surrounding discussion](https://arxiv.org/html/2508.20294v3#S4.SS2.SSS2) describes cross-modal alignment with stochastic state z, explicitly excluding deterministic h; its training discussion includes updates to the cross-modal maps. The current pinned [WorldModel.loss](https://github.com/frankroeder/DALI/blob/5ca393468defffe79e4e3537ba9766f6d31b510b/dreamerv3_compat/dreamerv3/agent.py#L358) instead passes concat(deter, flattened stoch). Its [reconstruct_wm_state_loss](https://github.com/frankroeder/DALI/blob/5ca393468defffe79e4e3537ba9766f6d31b510b/dreamerv3_compat/dreamerv3/nets.py#L103) stops gradients through recon_wm_state in loss1 and through wm_state in loss2.

Consequently the current source's first cross-modal projection receives no gradient from this loss, although its value affects the loss. This is a code-path fact to qualify by actual native gradients and saved training checkpoints. It is not yet an explanation for any forecasting failure, proof of paper error, or evidence that the authors used this revision for their experiments. The original paper objective and this released core must not be silently equated.

The already frozen2000-update factual transfer continues with the unchanged source. Do not swap in a paper-faithful objective mid-run. A conventional objective-correction control, if needed, must be separately registered with matching data, seed, update count and explicit parameter accounting. No method novelty follows from correcting a gradient path or choosing the documented target.

Nearest prior art remains [Interventionally Consistent Surrogates for Complex Simulation Models, NeurIPS2024](https://papers.nips.cc/paper_files/paper/2024/hash/26b8e3dc3a21fcd660d80c63b767f324-Abstract-Conference.html), which learns surrogate consistency under interventions using causal abstractions. Its [2023 arXiv predecessor](https://arxiv.org/abs/2312.11158) has a different title and onlyv1; an assumedv4 URL was404 and was discarded. Generic observational prediction versus interventional consistency is already studied.
