# C48 competing hypotheses

H0: ordinary full-history regression or recurrent state already provides useful future evolution and real-observation continuation. Primary controls test this; do not infer new-method need from NODE alone.

H1: explicit delayed evidence improves learning efficiency over a recurrent state. Compare complete frozen fits, parameter/cost records and independent future metrics. This is an existing mechanism, not a novelty claim.

H2: learning delay locations matters beyond adding fixed memory. Fixed/learned NDDE share source, initial delays/weights, data, loss and schedule; retain both results.

H3: any apparent advantage is a solver, interpolation, clock, boundary, information or training artifact. Numerical qualification, postselection VAL refinement, independent source-window and model replay address distinct parts; active training caps still limit interpretation.

H4: a static learned memory prior substitutes for dynamic evidence retention. Retrieval equations alone cannot establish this; current history-gradient profiles only characterize one functional, with cancellation possible. No new static-bank model comparison is claimed.

H5: a distinct framework-level memory learning interaction has independent-domain utility. Not tested by these existing arms; a concrete new method and fresh confirmatory protocol remain required.
