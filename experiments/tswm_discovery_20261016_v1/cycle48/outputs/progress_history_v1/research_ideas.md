# C48 development lead, not accepted direction

Current lead: understand which learned memory representation remains useful when a time-series model must continue physical evolution without observations and then use real new observations. The executed comparison adds a source-grounded explicit-memory family to prior strong controls on two real processes. It is designed to decide the next mechanism question, not maximize a dataset score.

No new architecture is proposed merely because delay equations or observers exist. A known-component framework remains eligible if a distinct necessary learning interaction and independent utility can be demonstrated. Generic SSM expressivity is not an automatic veto.

Fallback: temporal measurement-support transfer, where interval averages are different operators from point samples. Integrated GP and field-layer alignment are close existing mechanisms; its current novelty is unresolved and no new-method effect is claimed. Unknown-regime adaptation remains another unselected lead with substantial prior art.

Do not recommend any of these as a completed final direction. Finish the frozen memory screen, inspect actual failure attribution, and choose a new interaction only if it survives strong controls.
