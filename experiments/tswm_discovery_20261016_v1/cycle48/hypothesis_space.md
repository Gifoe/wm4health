# C48 adjudicated hypotheses

H0 ordinary history-aware controls already cover useful forecast/update behavior: supported within this two-process protocol.

H1 current explicit delays reliably beat recurrent state: unsupported; Jena favors GRU, ETT varies by seed.

H2 learned delay locations improve beyond fixed locations: context-dependent; Jena update mean improves but open-loop mean worsens. This is existing-method utility, not a new learning interaction.

H3 the scored differences are explained by a detected solver/window/replay failure: not supported by qualified numerical checks; no numerical flags. This is not a claim that all training confounds are excluded.

H4 static learned associative slots substitute for dynamic episode memory: not tested here. The inspected gradient functional cannot identify missing information or causality.

H5 a new framework-level memory interaction has independent-domain utility: untested and not accepted.
