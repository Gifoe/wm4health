## Existing arms, not new methods

1. NODE: actual author MLP, current signal plus known calendar, no past-state access beyond the current value. Diagnostic weak control only.
2. Fixed NDDE: actual author MLP using current and two delayed signal/calendar vectors; delays .271 and1.229 days fixed.
3. Learned NDDE: same initial weights/delays as fixed NDDE per seed. Delays learned and projected into[2/24,3]days after each update. Initial delays avoid an exact interpolation knot; this is a numerical choice, not VAL/EVAL tuning.
4. GRU: actual author single-layer GRU, hidden32; head adapted to scalar residual output, open-loop48-step training. Same calendar information; history96. Output delta initialized0 so all neural arms begin at persistence.
