# C53 native-process recovery

After 28 predictive fits plus the shared codec completed, PatchTST observation-space seed 3 terminated with Windows exception 0xc0000005. Application Error event 1000 identifies nvcuda64.dll version 32.0.16.1656 as the fault module. This identifies where the crash surfaced; the root cause is not established. The native Python exception handler did not run, so the last per-fit RUNNING state is historical. The supervisor observed process exit 3221225477, missing terminal summary/checkpoint and stopped. Both dependent monitors stopped without opening transfer evaluation.

The failed attempt's initial tensors, config, 27 completed epoch records, log and normalized fault event are retained. At least 162 optimizer updates were wasted; partial work after the last recorded epoch cannot be counted exactly. They do not count as a completed comparison fit. No selected checkpoint existed for this attempt.

V7 reuses the 28 validated predictive checkpoints and codec without refitting. It retries the failed cell once from the same seed and config in a new folder, compares every initial tensor and the complete config to the failed attempt before any updates, and enables Python faulthandler. It retains the original architecture, inputs, optimizer, loss, budget, dropout, selection and existing PatchTST-concat microbatch policy. No driver update, global environment change, model retuning, new seed or optimizer warm start is introduced. A repeat failure stops the queue for inspection.

Active recovery sources are train_native53_v7.py / capture_native53_v7.py. Evaluation uses capture_eval53_v3.py / score_native53_v8.py; the only score-code change is the current supervisor-state filename. The selection seal keeps the V6 schema/name and explicitly identifies the V7 writer. Independent verification and the preregistered analysis code stay unchanged. capture_analysis53_v2.py follows the new evaluation monitor and additionally writes explicit native prior-role/coverage and scaling/timing diagnostic summaries. These diagnostics do not select methods or alter the frozen comparison.
