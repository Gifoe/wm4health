# Negative evidence

The input roundtrip is not negligible for the existing raw predictor; output roundtrip also changes forecast risk. Both-side transport is not a uniform improvement over decoded training. These observations contradict simplistic attribution of all residuals to the latent transition, but do not uniquely prove an encoder/decoder cause. Existing ordinary decoded training already reaches the predeclared Val band, so the conditional18-fit branch remains untriggered.
