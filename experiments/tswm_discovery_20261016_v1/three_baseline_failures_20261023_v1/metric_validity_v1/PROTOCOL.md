# Metric-validity probe: temporal cosine versus unchanged forecast behaviour

This is a new evaluation-assumption audit, not a continuation of Electricity score tuning. The earlier architecture/capacity branch remains stopped. No model is trained, reselected or calibrated to improve prediction.

Primary motivation: [LatentTSF v2, Sec5.6 and AppendixG](https://arxiv.org/html/2602.00297v2) defines Temporal Transition Consistency(TTC) as cosine similarity of consecutive states. The pinned released repository search did not locate the corresponding TTC/CKA/effective-rank evaluation script. Therefore this probe implements the stated TTC formula, with epsilon1e-8, and does **not** claim exact reproduction of the paper's Table3/11 values or its unspecified sampling details. It makes no allegation that those values were computed incorrectly.

Use the original native DLinear/H96/seed42 checkpoints for ETTh1 and Electricity, the released AE, original configs, raw data hashes, chronological splits and train-only normalization. Do not use the adapted fixed100 or decoded-loss controls from the stopped case. Verify source/AE/checkpoint/data hashes and qualify the native forward on the first32 original Test origins against saved predictions. Test is only a replay fixture. Probe metrics on Validation only.

For each dataset create two separate state banks: (i) pointwise AE encodings of all unique Validation observations, and (ii) predicted latent sequences at32 evenly spaced Validation origins. Consecutive pairs are formed inside each sequence; never join the end of one forecast to the start of another. The observation bank is a representation diagnostic, not a forecast. Retain the unencoded observation bank as a descriptive reference.

Fix scalar offset sizes c in{0,1,4,16} times a power-of-two scale rounded from the RMS of encodings of512 evenly spaced TRAIN observations. Offsets are identical across latent coordinates. Define E_c(x)=E(x)+c, F_c(z_c)=F(z_c−c)+c, D_c(w_c)=D(w_c−c). These algebraic wrappers use unchanged learned weights and exactly preserve the physical forecast in exact arithmetic. Use float64 for add/subtract bookkeeping and qualify recovered float32 inputs and decoded forecasts against the original forward with the existing2e-5 scaled bound. This is a functionally equivalent wrapper, not a claim that every reparameterization is a symmetry of the original training objective or parameter class.

For both state banks and every offset report TTC, globally mean-centered TTC as an ordinary diagnostic, and a null using32 fixed within-sequence temporal permutations(seed20261023). Report zero-norm-pair counts; with the explicitly declared epsilon all pairs remain counted. A coordinate reversal is a negative control for cosine invariance. All offsets and shuffles are retained, never selected by a favorable score.

This asks whether TTC alone certifies learned temporal behaviour. Its sensitivity is not automatically an algorithm defect, a novel metric, or proof that latent states lack useful information. Representation-invariance choices have prior art: [Kornblith et al., ICML2019](https://proceedings.mlr.press/v97/kornblith19a.html) explicitly distinguishes orthogonal/scaling invariance from arbitrary invertible transformations and explains why stronger invariance is not universally desirable. Centering or renaming a known invariance test is not a new world-model method.

Store state banks and permutations only on server G storage, compact configs/results/source hashes on GitHub. No new pipeline is selected on Test. A positive descriptor-sensitivity result needs a separate novelty and behavioural-relevance argument before becoming a research direction; otherwise preserve it as a bounded evaluation warning.
