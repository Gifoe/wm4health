# C67 frozen real-task mechanism comparison

## Question and novelty boundary

Does a corrected native pretrained transition model lose predictive utility because its future covariate query and historical candidate features are encoded under different channel/length views? Competing explanations include coordinate indexing, contextual feature mismatch, time-position normalization, inadequate action information and ordinary local estimation. This is a mechanism comparison on a supported task family, not a new proposed method, exact paper-table reproduction or causal-effect test. ALER-TI already studies incomplete-query/complete-candidate alignment for time-series imputation; plain alignment/re-encoding is existing methodology. C65's small causal MDN results do not prove that every reusable framework is unnecessary; they only reject that cycle's claimed need on its two systems. Component familiarity alone does not rule out a useful new framework, but no such framework is established here.

## Data, splitting and fixed cases

Use all45 independently verified CGMacros1.0.0 participant numerical files. Primary task is retrospective known-meal conditional prediction of Libre GL, with Carbs, Protein and Fat supplied as known covariate channels. This follows the paper's physiological/nutrition task family, but exact preprocessing/splits are independently specified because complete author evaluation code is unavailable. Logged future meals are given conditioning information here; no deployable forecast of unannounced meals or identified clinical effect is claimed. Do not use future HR, Dexcom, Libre values or phenotype labels as inputs.

Sort the actual45 participant filenames; permute with NumPy default_rng(67021). First27 are TRAIN, next9 VALIDATION, final9 sealed EVALUATION. Freeze this split and case identities before executing any model. Metadata/quality auditing of all sources is allowed; no forecast score on EVAL before VALIDATION selection is written and hashed. EVAL is not used to add or tune methods.

Each case observes2880 minutes and predicts720 minutes, matching the paper's declared maximum context and horizon. For each participant choose row-index forecast starts2880,5760,8640,11520; include only complete windows with exact one-minute timestamps throughout. Use source-provided Libre values; permit causal forward-fill for at most15 missing minutes, without backward fill or future interpolation. A context must be finite after this fill; score only finite source-provided target values, requiring at least95% target availability. Exclude a case with a missing/nonfinite declared meal value on a row labelled a meal. Outside meal rows, absent macronutrients represent no recorded meal and are zero. Preserve all exclusions/coverage. The source already reports one-minute series despite15/5-minute sensor acquisition periods; provenance of the resampling procedure is not fully documented, so scores describe released numerical trajectories, not fresh independent sensor measurements.

History is[Libre GL,Carbs,Protein,Fat]. For Bayesian inputs, z-normalize each channel with its observed2880-point mean/std (sample std, zero std->1, +1e-8); do not clip. Clear all hidden future Libre values before input construction. Known macros stop at horizon720; append exactly16 synthetic points by repeating each last known macro value, so the native +1 latent-patch request can execute without supplying actual observations beyond the declared horizon. The extra response values are zeros. Native predict/simulate keep their own declared internal normalization, with their information/preprocessing differences explicit; the Bayesian geometry comparisons use identical normalization/core/transitions.

## Fixed methods

1. Context mean, last value and previous-day seasonal copy. These use no future meals and are low-cost sanity controls.
2. Native pretrained predict, public max_pred_length=16, history only. It is an unconditional information ablation, not a matched-future-meal baseline.
3. Native simulate with the already qualified hidden-channel-only recurrent update and output cropped to declared length. It receives known future macros. Original source bytes remain untouched.
4. Native latent transition, condition_bayes=False, action_channels=[1,2,3] explicitly nonempty to enforce history-only state encoding. This ignores future meal matching but retains identical fitted transitions.
5. Same native conditional transition with corrected feature-major action indices. This is the corrected native comparison baseline.
6. Same fitted transition/sampler, but form action-centroid features by re-encoding historical action channels alone and averaging those features under the unchanged joint-state cluster assignments. Future action query encoding remains native. This is an ordinary channel-view consistency control.
7. Same as6, but take historical action features from the SAME action-only full known-plan encoder pass as the future queries. This is an ordinary channel-and-position-view consistency control.
8. Same fitted transition/sampler using observed raw16-minute macro-patch means and known future macro-patch means for its distance calculation. This is an ordinary raw-covariate neighborhood control. No future response is used.
9. Train-only conditional analog forecasting: encode history Libre into96 consecutive30-minute means and the known future macro plan into12 consecutive60-minute sums for each of3 macros; train-bank windows stride720, context-normalize Libre by each train case; covariate feature scales use TRAIN only. Retrieve k in{1,4,16} and average the normalized future Libre paths, then restore current context scale/mean. No EVAL/VAL trajectory enters the bank. Choose k by VALIDATION only. This conventional baseline is not a proposed framework.
10. Train-only direct ridge forecasting, same feature vector as9 with an intercept, alpha in{1,100,10000}. Standardize features with TRAIN statistics, fit all720 normalized response coordinates, choose alpha by VALIDATION. This baseline has target-domain training information and is grouped separately from context-only native adaptation. It tests whether ordinary supervised reuse already suffices; no equal-training-compute claim.

Bayesian num_states=int(log((2880//16)**2)+.5)=10, num_traj_sampled=4,3 fixed MC seeds2021/2022/2023. Same seed is paired across conditional-feature methods; it does not create three independently trained models. Future physiology never enters the model. KMeans and all native sampler logic remain unchanged except explicitly supplied centroid/query distance features. Do not interpret weighted sample fusion as a calibrated predictive law.

## Selection, evidence and stopping

Primary endpoint is per-case Libre MAE normalized by observed-context std, aggregated first within participant then across participants. Also report mg/dL MAE/RMSE and individual case/MC values. Main contrast: ordinary same-full-view control versus indexed native conditional. Report the action-ignored and raw controls, and the separate train-only analog/ridge group, including unfavorable cells. Save every forecast on G with hashes. Report parameter/source identities, model calls and runtime; no hidden HPO or architecture replacement.

Run VALIDATION first, freeze selected k/alpha in a receipt and hash it before EVAL. Evaluate all predeclared native/feature-control arms, not just the best validation performer. No method changes after inspecting EVAL. Report paired per-participant differences; optional fixed10000 participant-bootstrap resamples, seed67025, are descriptive in this discovery study and do not turn9 people into many independent windows. No paper-ready generalization or novel-framework claim follows from one dataset. A positive view-control effect remains an existing-method repair; a null effect eliminates the current explanatory hypothesis. A surviving substantive gap must later show independent-mechanism evidence and a method distinction beyond these controls.
