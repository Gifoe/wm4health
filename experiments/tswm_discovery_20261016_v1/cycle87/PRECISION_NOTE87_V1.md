# Native precision contract and bounded numerical reference

The first supplementary native DOP853 check used rtol1e-5/atol1e-7 on a float32 neural vector field and completed no first-cohort metric after sustained CPU work. It was explicitly stopped as a resource-inefficient diagnostic; the training/evaluation jobs were already terminal. Its capture exit and stop receipt are retained. An attempted full float64 cast failed because the unchanged OpenFIM linear-attention feature-map path explicitly casts keys/queries to float32, which is incompatible with double-valued attention values. This diagnostic failure is not a new research gap or a changed learned model.

The replacement native reference uses independent RK45, rtol1e-3/atol1e-5, max_step.1, with a hard12000-function-call cap per cohort and progress every1000 calls. It compares fixed and worst-amplitude case trajectories against the saved RK4 result, requiring trajectory-RMS-relative difference below1%. Both methods evaluate the unchanged native float32 field; no weights or reported native predictions are altered. The reference precision is explicitly limited and cannot certify sub-tolerance effect sizes.

The empirical-prior polynomial field supports float64 directly and retains a tighter independent DOP853 reference, rtol2e-10/atol2e-11. Affine flows use exact matrix exponentials with a stricter independent.05-versus.0125 transition check. Full-population nonlinear learned-rollout reintegration is not claimed. All reported sampler effects must be interpreted with these limits; the source/test ordinary-control dominance is a separate comparison.
