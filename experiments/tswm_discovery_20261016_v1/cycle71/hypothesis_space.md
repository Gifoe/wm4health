# Competing explanations to retain

| Observation or proposed claim | Competing explanation | Discriminator |
|---|---|---|
| A modular model transfers better | Extra parameters, training or source information | Match capacity and actual update/compute costs; compare complete existing modular baselines. |
| Frozen experts fail after representation updates | Coordinate/interface drift rather than missing physical mechanisms | Existing alignment, replay and frozen-feature controls with equal observation access. |
| High edge accuracy implies faithful simulation | Graph labels need not uniquely determine learned continuous transitions or uncertainty | Evaluate permitted observable future laws and task consequences, not only structural labels. |
| Partial observations require a new framework | ModularNRI/SICSM and conventional state inference already handle important cases | Execute their supported contracts; state precisely what remains different. |
| A low native subset score proves a new gap | Training, finite data, search budget or implementation mismatch | Source-body checks, curves, actual optimizer counts and competent existing controls before attribution. |

These are falsification conditions. No held-out EVAL score has been used to choose a candidate in this phase; code acquisition and file-integrity checks do not expose EVAL forecast quality.
