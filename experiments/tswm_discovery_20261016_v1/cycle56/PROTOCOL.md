# C56: finite-reference gradients at a known population truth

This is a mechanism discriminator, not a new method, paper reproduction, or accepted research direction. C54 found a learned-parameter deficit; C55 established a correct attainable ideal scalar population optimum. C56 tests finite reference sampling separately from optimizer trajectories. No old fit, readout, dataset, package or upstream file will change.

Use RP-GSSM revision a75225d5edceb972bb872dc9a335608733567dd4 and the existing CPU runtime. Verify all 21 pinned source hashes before and after execution. Qualify the independent finite loss AND its derivatives against the unchanged native source for full differentiation and the released fixed-posterior EM convention. Check the exact-reference gradient by independent Gaussian sigma-point averaging and central differences of the C55 expectation. Stop on a failed qualification; retain the failure.

Data law: stationary scalar Z with variance one, a*=0.95; X=Z+sqrt(r)*noise. Fix r in {0.3,3}, T in {6,24}. Evaluate at the known true parameter (a*,log(1/r),log(1)). No fitted parameter is selected. The native reporting jitter is 1e-5; also check zero jitter for B=32 in all four cases. Recognition potential is N(z;b*x,1/lambda); the full recognition factor includes the prior.

For each case fix 256 independent Monte Carlo banks (seed 5601 plus case index), maximum reference size 512. Shared prefixes of the same banks supply B in {4,16,32,128,512}; a second independent bank supplies external references. Use M=min(8,B) target sequences from the first bank. Averaging a fixed prefix of targets has the same expectation as the full native batch average by exchangeability; it is a compute reduction, not a change to that expected objective. Native loss qualification uses all targets. Each reference item is an independent sequence; temporal correlation within a sequence is retained.

Compare (1) native same-bank references including each target, (2) independent external references, (3) leave-one-target-out references of size B-1. The last two are mathematical controls, not claimed native options or methods. Use both full differentiation and fixed q moments. Derivatives are with respect to (a,log(lambda),log(b)). Centering the loss by log(reference size) changes no derivative.

An analytically integrated reference normalizer is evaluated on the identical target sequences. Subtract its sample gradient from each finite-reference gradient to obtain a paired estimate of finite-reference deviation; add back the exact population gradient when reporting the gradient itself. This control variate has known expectation. Preserve raw gradients as well. It does not remove training bias or constitute a method. Verify agreement of the integrated target expectation with Gaussian sigma points before using it.

Report means, Monte Carlo standard errors, 95% t intervals and all gradient blocks. The prespecified primary family is eight same-bank a-gradient deviations at B=32: four data laws times two differentiation conventions. Use two-sided Bonferroni family-wise 0.05 t intervals for those eight tests. Other intervals and reference-size trends are descriptive. Monte Carlo banks are not training seeds or independent real datasets. No adaptive extension of sample count, optimizer sweep, or test selection is permitted.

If a true-point finite-reference deviation survives the primary interval, optimizer convergence alone cannot explain that mathematical deviation. It does not show that the deviation explains the magnitude of C54 failure, holds for all neural/nonlinear models, or is novel. If it vanishes with larger references, record finite-reference sensitivity; global-reference and contrastive-bias corrections already exist in prior work. If gradients are compatible with zero, retain that negative evidence. No architecture or final direction is accepted from this scalar test alone.

Large raw banks and per-replicate arrays go to configured G: artifact storage. Compact results, logs and source stay in the new cycle56 folder. Publish code and evidence to wm4health; no local result-file synchronization. The overall research goal remains active and unachieved.
