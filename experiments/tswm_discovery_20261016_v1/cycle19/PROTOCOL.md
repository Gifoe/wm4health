# Path-event-law falsification gate (no new method claim)

Question: Do source-native autonomous simulations that pass coarse geometry/spectrum checks retain ordered event statistics? Scope: existing cycle18 released DynaMix demonstrations, all3 systems and all3 fixed stochastic draws, with no source/weight changes or new neural fits. This is exploratory failure discovery, not an independent final benchmark or a claim to refute all DSR methods.

Primary source hashes and the three saved prediction-array hashes must match cycle18's seal and result receipt. Data and model remain unchanged. Primary event thresholds are computed from the original past context only, coordinate1: median and90th percentile. At landmarks0,100,...,9900 of each10,000-step future, select starts at or below the context median and count whether the upper threshold is reached within the next10/50/100 samples (including the start). Last100 samples are fully observable, so no unseen-future censoring or imputation is used. Report eligible landmark counts and all three CDF values. A second, explicitly descriptive rank-normalized diagnostic uses each evaluation path's own median/90th percentile, to separate marginal-amplitude mismatch from ordering. This uses reference data only to define an evaluation statistic, never as model input or calibration.

Other frozen summaries: positive median-crossing return-time CDF at10/50/100 and number of returns; time-reversal-odd moment E[x_t²*x_(t+k)-x_t*x_(t+k)²] atlags1/5/10 in fixed context-standardized coordinates. Report events/counts rather than silently discarding unfinished returns. Crossings at the end without a subsequent crossing are recorded as right-censored; return CDF uses completed intervals and is labeled potentially censor-biased, therefore not primary evidence.

Finite-series controls: reference early/late halves are scored separately. Use nonoverlapping500-sample blocks (20 blocks per full path),2000 block-bootstrap draws seed20261901, and paired displayed max-CDF discrepancies only as descriptive uncertainty. No formal coverage/mixing guarantee is asserted. Bootstrap landmark sufficient counts within each500block, so their dependence is preserved. Reference has only one future trajectory per system; stochastic model seeds are not independent training or physical-system replications.

Ordinary dynamics control: nearest-neighbor successor resampling on full3D context states,8 neighbors including the exact matching point if present; start at the nearest past transition-origin to the last context state, then repeatedly choose one neighbor and jump to its observed successor. Past transition origins0..CL-2 only; precompute neighbor lists for every context state. Seeds2021/2022/2023,10,000 steps. This old analogue/Markov control has identical past information but is not a complete VAMP/MSM or generative-model benchmark. Existing context-replay control is also retained. No use of reference future to fit either control.

Validation witness: a stationary3-state directed circulant Markov chain and its time reversal have exactly equal stationary state distributions and all scalar autocovariances, but different directed first-passage laws. Verify by matrix powers and an absorbing-chain formula. This is a classical metric-insufficiency example, not a novel theorem or a measured neural failure. It checks the audit, not scientific novelty.

Decision: a generic event-law gap is not new (Markov-state models,VAMPnets,transition-path theory and stochastic DSR already study kinetics). Only a consequential residual across competent modern reusable simulators would merit a new research problem. If observed differences are small, statistically unresolved, removed by marginal/rank controls, or handled by ordinary analogues, abandon this candidate. If not, require independent longer reference data, meaningful task consequences and strong existing kinetic/generative methods before method design. No new architecture selected; accepted novel directions0; overall goal remains active.
