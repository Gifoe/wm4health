# Ordinary per-context system-identification control

Fixed after inspection of the event pilot and noise/history ablations, before running this control. This is exploratory falsification, not an independent confirmation or a new method. It addresses whether a generic, fully observed, per-system vector-field fit is a plausible competing explanation for apparent path-law deficiencies in a pretrained model.

Five tasks: the original Lorenz63/Chua/SprottM demo origins (2000/1028/512); Chua at origin2000 using either its last1028 or all2000 past samples. Common-origin metrics and event thresholds use the last1028 context in both arms. All use the same10000-step future as existing native arms. The three original tasks and two Chua controls are not five independent systems.

The ordinary model is dense ridge regression of central-difference increments against degree2 or3 polynomial state features, optionally augmented by univariate positive-part hinges at each coordinate's past deciles. No known system equations, physical time step, pretrained weights, future labels, or fitted noise are supplied. Time unit is the sample index; this is not an exact SINDy-paper reproduction. Classical library-based system discovery is established prior art (Brunton, Proctor and Kutz, PNAS2016, doi:10.1073/pnas.1517384113).

Select from degree{2,3} x hinges{off,on} x relative ridge{1e-8,1e-5,1e-2}. Fit only the first floor(.8*context length) past samples. Feature scaling, state scaling, and hinge locations are fitted only there. Validation uses64-step free rollouts beginning at context-only origins from the split to length-65, stride32, with an observed state at each origin and no later assimilation. Minimize normalized squared error over these validation trajectories, then refit the selected specification on all past samples. The selected model emits the first future state after one RK4 step from the last past observation. RK4 uses4 substeps per sample index for all tasks, without test-driven changes. Absolute normalized state beyond1e4 or nonfinite output is a recorded divergence, not clipped into an attractor.

Keep every validation score, specification, coefficient/scaling arrays, complete finite predictions, divergence index, timings, script/plan/source-array hashes. Evaluate only finite, full10000-step rollouts with the existing frozen event helper and native geometry/spectrum/true-denominator MASE. Independent checks must cover linear-flow integration, exact library regression, model serialization replay, and event counts. A per-context fit has a different training budget from a frozen pretrained model; results only assess whether a sophisticated new architecture is necessary for this observed failure, not a fair universal-model leaderboard.

Gate: if ordinary fitting gives adequate global dynamics and removes the localized Chua event residual, reject architecture necessity. If not, do not infer novelty: finite-context identifiability, derivative estimation, model selection, missing library terms and reference-trajectory uncertainty remain competing explanations. No further tuning on these test trajectories.
