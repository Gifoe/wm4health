Motivation: C88 fixed an anticipation defect by ordinary manager reindexing, while post-edit response quality remained mixed. That defect and its repair stay closed. A separate candidate is that macro action aggregation conflates different within-window control orders. Source inspection already weakens this explanation: native MTS3 concatenates an explicit within-window timestamp to every action before encoding. It must not be described as an unordered action bag.

Use the existing C88 stock, ordinary lagged, native acRKN and conventional GRU checkpoint, each selected only by original factual validation MSE. No training, checkpoint reselection, changed normalization or parameter tuning. This is a developmental source-based transfer diagnostic, not another primary-paper reproduction. Three primary papers remain WorldTS, LatentTSF and the TSWM benchmark/recipe.

Use all64 existing C88 validation trajectories. Preserve their65-observation prefix, hidden physical state, hidden system parameters and shared observation-noise realization. The learner receives only its original16 observed channels, two actions and observation-valid mask. Future observations are zero/masked exactly as before. Source simulator states/parameters are used only to construct counterfactual reference trajectories, never for model inference. Reserved EVAL is not accessed. This bank participated in original factual checkpoint selection, so it is not independent confirmation.

Original horizon has32 future primitive controls at local indices64:96, each source action block lasts8 steps. Fixed comparisons: identity; exchange first and last8-step blocks; exchange middle two8-step blocks; reverse the four8-step blocks. These preserve exact action multisets, per-channel sums and amplitudes. Under the source generator, future8-step action blocks are IID and independent of the current state, so these permutations do not deliberately invent impossible action amplitudes. Still report them as new action queries, not factual data. Do not select a favorable permutation.

Replay the original base forecasts against the prior saved arrays within1e-6 absolute tolerance and qualify simulator factual continuation within1e-5 standardized units. Identical identity controls must produce identical mean forecasts and truth. For every arm/family/permutation report factual and edited MSE, response RMS, zero-response-reference RMS, response error/reference ratio, flattened response cosine, endpoint response error and shared-prefix maximum change. Zero-effect denominators are marked unavailable, not regularized into impressive scores. No threshold sweep or new method is selected on this diagnostic.

For native stock MTS3, evaluate its actual abstract-action encoder and Gaussian aggregation at the same selected weights. Compare (a) reordered actions with timestamps fixed to their slots, and (b) jointly reordered action/timestamp pairs. The latter should be invariant up to1e-6 scaled numerical tolerance; the former need not be. The full fast path also receives ordered primitive actions. An order-sensitive abstraction or forecast rejects exact permutation blindness; it does not by itself prove correct dynamics. High response error does not uniquely identify an abstraction bottleneck, given only1000 original training updates and one seed.

Closest existing mechanisms: [MTS3](https://arxiv.org/abs/2310.18534) already timestamps abstract actions; [HWM v3](https://arxiv.org/html/2604.03208v3) uses a learned action encoder for endpoint macro-actions; [Log-NCDE, ICML2024](https://proceedings.mlr.press/v235/walker24a.html) provides existing order-aware path compression. Signatures/log-ODE and ordinary chronological encoding are baselines, not a novel mechanism claimed here. A naive order-loss argument is rejected if source and execution show order is available. An eventual research direction would need a remaining accuracy/cost tradeoff beyond these controls on independent systems, which this frozen probe cannot establish.
