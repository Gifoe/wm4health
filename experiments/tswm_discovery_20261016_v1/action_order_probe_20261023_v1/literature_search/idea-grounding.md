# Grounding packet

Source-supported: controlled-identifiability work already links excitation to counterfactual error; matched-intervention work already separates capture from propagated physical effects and tests support/disagreement. MTS3 already time-encodes action sets. HWM learns macro-action endpoint representations. DALI explicitly exposes context perturbations as physical counterfactuals. Local low-rank state-edit interfaces already have controlled evidence.

Experimental observation from this project: time/order information is actually used by the selected MTS3 abstraction; all four frozen neural models beat a zero-action-response predictor on the registered reordered queries, with substantial remaining error. This rejects exact blindness, while limited training/one seed prevents a unique residual attribution.

Inferred candidate: a parameter/context edit should correspond to one changed dynamics across several roots and action queries, whereas a local physical-state edit has a different contract. This follows from the intended semantic use, but absence of such a test in retrieved sections is not evidence of model failure or novelty.

Minimal decisive protocol if feasible: first establish unedited native rollout and same-initial-state capture; fit one simulator parameter vector for an edit using CAL roots/actions; freeze it; assess other roots/actions without per-query refitting. Ordinary manifold/projection and explicit-context controls can falsify a new-mechanism motivation. If no accurate native model can be qualified, do not interpret arbitrary latent perturbation outputs as research evidence. No method is accepted now.
