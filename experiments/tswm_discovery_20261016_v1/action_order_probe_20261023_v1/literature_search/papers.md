2026-10-23; exploratory search, primary sources only. Starting evidence is the focused three-paper failure ledger and C88's mixed action-response residual. Related work is used to define tests and differentiation, not to reject an entire field from title overlap. None of these newly inspected papers is counted as another completed baseline reproduction.

Provisional1–5 scores assess only the retrieved sections/code, not overall paper quality or acceptance potential. `NR` means insufficient full-text inspection to rate; it is not a low score. This prevents inventing confidence from an abstract. ## Opportunity map

- **Conditional-support uncertainty: covered central claim / crowded but open.** Generic ensemble reliability, excitation failures and support correction already have close prior work. A possible differentiation is finite-sample, query-specific uncertainty under partial observation, but no current native failure or repair beyond ordinary identification has been established. Do not train from this generic wording alone.
- **Action-order compression: known mechanisms and current falsification.** Source and frozen execution refute an order-blind-bag explanation. A remaining efficiency/fidelity tradeoff would need comparison with existing time encoders, chronological recurrence and Log-NCDE. Current probe is negative evidence for the naive mechanism, not proof all abstraction questions are solved.
- **Global context-edit semantics: needs-search / empirical candidate.** A fixed edit that looks physically plausible for one passive rollout may encode a state change, a mixture of parameters or arbitrary drift. Test one shared changed simulator parameter vector across held-out roots/action plans; compare no edit, equal-norm random edits, context-manifold projection, deep context conditioning and a parameter-conditioned oracle. Native factual competence and state preservation come first.

Single5090 feasibility: frozen existing Torch models are available. Native DALI currently has no checkpoint-named files or GitHub release assets in the inspected pin. The checked server runtime has no JAX/JAXlib/MuJoCo/DM-Control and no WSL executable. This is a preparation cost, not model failure or a permanent block; avoid presenting a PyTorch substitute as native DALI.
