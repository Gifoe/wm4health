# C46 development judgment

Target: a reusable time-series world-model framework, with data used to test capabilities. Cheap ordinary alignment/SSM already competes with or beats the neural combinations on held-out path quality; a missing new world-model mechanism is not established.

The current observation-evidence/dynamics composition question is a development lead, not an accepted novel direction. A new recipe must define an additional useful responsibility and a discriminating experiment against the strongest ordinary complete combination. Simply changing MLPs, adding a decoder after RP-GSSM or calling ordinary inference “prior-aware” does not do so.

A narrower rescue is a compatibility protocol for noisy observation/dynamics reuse, but benchmark novelty must be checked against DCFM, DiLA, Meta-iLaD and existing time-series world-model evaluation. One synthetic carrier cannot support a benchmark-paper claim. The broader fallback is to change the research question using a newly verified source-backed failure rather than tuning these scores. No second/third final direction is recommended.
