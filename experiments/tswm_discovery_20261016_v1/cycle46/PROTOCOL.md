# C46 — neural ordinary-composition falsification screen

The target remains a reusable time-series world-model framework. This screen asks whether a complete ordinary observation/dynamics composition already provides the proposed reuse capability. It is not a new architecture claim, a recreation of a paper leaderboard, or evidence that a generic SSM graph alone resolves the research question.

First qualify an ordinary generative-path adapter of the pinned C45 NCDSSM core: independent auxiliary history draws, native filtered state posterior, proper state propagation, auxiliary/observation emission. Constant diagonal-diffusion nonlinear SDEs use Euler–Maruyama with a stated step size; linear dynamics use exact transitions. Native marginal-time forecasts remain a separately defined API. Validate linear joint moments and coupled-step nonlinear convergence. C45 discarded weights may be used only for numerical qualification, never a comparative model.

Then fit four complete native-core Gaussian-state models: observation maps conditioned on view+system versus view-only, crossed with unconstrained system-conditioned stable linear generators versus additive stable generator primitives. All use neural recognition/observation maps, source auxiliary ELBO and native continuous-discrete filtering, the same four-dimensional latent/auxiliary states and exact joint future simulation. Observation networks share their architecture and parameter shapes; the unconstrained dynamics control has slightly more parameters. These are ordinary controls, not four new methods. Report actual parameter counts and update/time budgets; do not assert isolated architecture superiority.

Carrier: four stable4D linear stochastic systems, initial N(0,I), exact discrete transitions at delta=.25,24 observations. Four unknown nonlinear invertible view transformations followed by8D noisy projections. Learners receive only observations, view identity and two system bits; no latent states, matrices or true noise. Observation identity is invariant across systems in the generator. Twelve view–system training cells, four diagonal cells held out. Same64 synchronized static four-view TRAIN anchors from the initial-state population for every model; these contain no temporal transition or latent labels. Thus a held-out cell can have static anchor information, not temporal training data. TRAIN64 independent trajectories/seen cell, VAL32/seen cell only, sealed EVAL128/held-out cell plus64/seen cell. TRAIN-only per-view normalization. No future-known observations are inputs.

Two initializations2026461/2026462, eight fresh fits. Shared precomputed minibatch schedules, batch16; every fifth update is an anchor batch, otherwise uniform seen-cell sampling. Adam1e-3, weight_decay1e-5, clip10. Minimum1000 updates; evaluate every250 using fixed first8 VAL histories/cell and32 joint future draws. Select minimum mean joint energy. Stop after three checks with less than.2% relative best improvement after the minimum. Soft cap4000, extend to8000 only when the selected checkpoint is at the cap or either last two checks improves best by at least.2%; otherwise stop. Cosine LR to10% over8000. Qualification weights excluded. No held-out EVAL for stopping, structure, hyperparameters or selection.

Static anchors are sampled from the common initial population; each anchor minibatch receives a uniformly sampled system label because that population is identical for all systems. All four views of that static state are available together. This includes static evidence for diagonal cells and is not zero-shot with respect to observation alignment. Temporal holdout is the tested capability. CPU versus CUDA is selected only from discarded TRAIN-only throughput qualification; two concurrent CPU fits or one CUDA fit, no global environment changes. Schedule identities and training times are recorded.

Primary evidence: held-out versus seen conditional joint future energy /sqrt(16*8), mean-prediction MSE and marginal90% coverage. Preserve per-origin scores,64 future draws/origin, source/data/config/selected-weight hashes. Independently score retained arrays. Four held-out cells and two initializations are a viability test, not cross-domain validation or a reliable population significance claim. Interaction and seen tradeoffs matter; '11 is best' is insufficient. If the complete ordinary combination covers the target, no extra recipe is justified by this screen. If it fails, distinguish optimization, representation, inference and composition before proposing a new learning mechanism. This cycle cannot by itself establish novelty or conference readiness.
