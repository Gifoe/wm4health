# C68 controlled contextual-operator audit

The complete pretrained NormWear-2 and an independently pretrained author system-identification Transformer executed on24 independently seeded controlled systems. 480 point forecasts and their raw arrays were retained; independent replay passed. No neural model was trained this cycle. Nine ordinary latent-operator settings and six raw-identification settings are tested on VAL; selected settings are frozen before EVAL. This is a new controlled transfer/mechanism comparison, not exact paper-table reproduction or a new method.

Read experimental_results.md for every fixed result. Raw data, weights and forecast arrays stay on server G; only authored source, compact results and reports are published.
