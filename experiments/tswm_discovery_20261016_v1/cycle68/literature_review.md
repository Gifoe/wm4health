# C68 source audit and novelty boundary

Retrieved2026-10-18. Primary papers/code only; third-party search summaries excluded from scientific conclusions. This is a focused delta, not an exhaustive six-month systematic review.

- [NormWear-2](https://arxiv.org/html/2605.15465), Sec3.5: context clustering and empirical transitions operate in frozen pretrained feature space. The public implementation permits the operator comparison here. Prior C66/C67 measurements remain the authority for its repairs and real-data scores. This cycle tests a new controlled transfer protocol, not the physiological paper tables.
- [Rufolo et al., probabilistic in-context system identification](https://arxiv.org/html/2610.13411), Sec3/4/6/7; [author source](https://github.com/PuraFilippo/sysid_benchmarks), [release](https://github.com/PuraFilippo/sysid_benchmarks/releases/tag/v0.1): synthetic Wiener-Hammerstein pretraining, context/query simulation, probabilistic output heads and long-context patching/ensembling already form a reusable simulation framework. They explicitly acknowledge classical identification's stronger asymptotic accuracy with abundant per-system data. Inspect exact source and execute the published checkpoint rather than proposing generic context-adapted dynamics as new. This paper's ID must not be mislabeled Meta-iLaD.
- [Meta-iLaD author repository](https://github.com/GoForIt-YYB/Meta-iLaD): current README describes few-shot environment inference and joint state/environment/dynamics identifiability. Only README and tree reviewed this cycle, not theorem assumptions or execution. Repository currently lists paper/poster but no implementation; that is not a research gap.
- [OSSM](https://arxiv.org/html/2609.33566): propagation/measurement-correction separation is an existing design. [RP-GSSM](https://arxiv.org/abs/2505.23569) provides recognition-parametrized probabilistic latent dynamics. Neither generic observer propagation nor reconstruction-free representation is new here. No new execution of those models this cycle.
- [DMDc](https://arxiv.org/abs/1409.6358) and [SINDYc](https://arxiv.org/abs/1605.06682) already estimate controlled transitions from observed trajectories. Our dense polynomial ARX is labeled an ordinary structural control, not an exact SINDYc implementation or new method. [ARGOSc](https://arxiv.org/abs/2509.09784), abstract only, is an additional modern sparse controlled-identification neighbor; do not claim polynomial fitting itself novel.

No candidate framework accepted. The experiment is designed to decide whether an ordinary context operator is a sufficient explanation before spending compute on representation redesign. Cross-domain failure and a missing public pipeline cannot establish novelty.
